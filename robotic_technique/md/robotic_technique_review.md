## 1. 総論

### 1.1 25年で何が起きたか

臨床第1例は 1998年初頭、Carpentier によるロボット僧帽弁形成（MVr）で、
その後 Chitwood が普及を主導した。冠動脈側はやや遅れて Loulmet らが
ロボット支援冠動脈手術の第1例を行い、robotic-assisted MIDCAB を経て、
数十年かけて完全内視鏡下冠動脈バイパス（TECAB）に到達している。

この25年で対象は僧帽弁を超えて広がった — 三尖弁、大動脈弁、両心房 Cox maze、
心筋切除、先天性、そして多彩な同時手術である。

普及の到達点を1つの数字で示すなら、**米国では一次性僧帽弁閉鎖不全に対する
弁形成術の5分の1がロボットで行われている**（STS 2026 コンセンサス）。
経験のある施設では、ロボットMVrは胸骨正中切開MVrと**コストも耐久性も同等**で、
複雑な形成や高齢者ではむしろ利点があると報告されている。

### 1.2 エビデンスの成熟度は術式で全く違う

「ロボット心臓手術」を一括りに語れないのは、**術式ごとに成熟度が3段階に分かれている**
からである。この差を意識しないまま導入計画を立てると失敗する。

| 成熟度 | 術式 | 現状 |
|:--|:--|:--|
| **確立** | 僧帽弁形成 | 米国の一次性MRの弁形成の20%。正中切開と同等の耐久性・コスト。適応と Pitfall がコンセンサス化 |
| **発展途上** | 冠動脈（MIDCAB / TECAB） | 単一施設で10年成績あり（BITA-TECAB）。ただし施設数が限られ、トロカール配置にも「流派」が並立 |
| **新興** | 大動脈弁（RAVR）・複合弁 | 側方アクセスRAVRとして2020年代に確立途上。国際多施設の縦断成績が出始めた段階。STS では Phase IV（習熟後）の術式に位置づけ |

### 1.3 本レビューの構成

第2章で**術式に依らない共通の土台**（患者選択の解剖学的閾値、術前CT、体位）を扱い、
第3章で**訓練とプログラム構築**を扱う。

第4章以降は術式別で、**各章の冒頭にその術式専用のポート配置**を置く。
これは意図的な構成である — 後述するように、ポート配置は術式ごとに
胸腔の左右・肋間・ドッキング方向がすべて異なり、共通化できない。

## 2. 共通の土台

### 2.1 患者選択 — 解剖学的な線引き

ロボットを使うか否かの判断で、術者が自問すべき問いは1つに集約される。
Cleveland Clinic の Gillinov らはこう書いている：

> 「ロボットを使って、**同じ手術を、同じ安全性と有効性で**行えるか？」
> Yes ならロボットは適切である。

彼らの最初の1,000例は死亡0・形成率99%、続く1,600例で適応を拡大している。
一次性変性僧帽弁疾患に対する期待値は **死亡率<1%・形成率>95%** で、
この水準を守れる範囲が適応の外縁になる。

#### 胸腔の奥行き — 最も重要な単一指標

| 胸骨後面〜脊椎前面の距離 | 判断 |
|:--|:--|
| **≥10 cm** | 理想。右肺静脈と左房の展開に十分な空間がある |
| **7–10 cm** | カメラを右胸に入れて**実際に見てから**判断する |
| **<7 cm** | 胸骨正中切開を選ぶ |

要するに「左房を吊り上げて僧帽弁を見るための空間があるか」であり、
数値そのものより*空間の確保*が本質である。

#### 末梢アクセス — 数値で切れる部分

| 所見 | 対応 |
|:--|:--|
| 大腿動脈径 **≥7 mm** | STS が導入期の初期症例に推奨する下限 |
| 6 mm 前後（borderline） | 直接カニュレーションを避け、**8mm グラフトを大腿動脈に縫着** |
| **<6 mm** | 胸骨正中切開、または両側大腿動脈からの送血 |
| 大動脈腸骨動脈の有意な粥状硬化 | 大腿送血は脳血管イベントを増やす。**軟性プラークまたはびまん性の硬性/石灰化プラークがあれば腋窩動脈送血** |
| B型解離・IVC断裂・IVCフィルター | 正中切開（予期せず見つかることがある） |

#### 心機能・肺循環・弁

- **大動脈弁閉鎖不全が mild を超える** — 順行性心筋保護が読めなくなる。
  ここは施設間で判断が分かれる（[2.5節](#25-意見が分かれる点)参照）
- **重症左室機能低下** — 相対的禁忌。特に導入期。順行性＋逆行性心筋保護と短い遮断時間が要る
- **重症固定性肺高血圧**（ほぼ体血圧以上）— 禁忌。それ以下なら 30℃ への全身冷却を併用して可
- **重症僧帽弁輪石灰化（MAC）** — Gillinov らは正中切開を選ぶ。ただしこれも争点（[2.5節](#25-意見が分かれる点)）
- **既往の右開胸** — 禁忌
- **既往の胸骨正中切開** — 経験のある施設なら可。上行大動脈のバルーン遮断＋
  順行性/逆行性心筋保護（内頸静脈経由の冠静脈洞カテーテル）が有利

### 2.2 術前CTで何を見るか

STS は**全ロボット心内手術例に 3D 再構成つきCTA を最低要件**として求めている
（冠動脈トラックでは心カテ＋経胸壁心エコーが最低要件で、CTAは任意）。
Gillinov らは胸部・腹部・骨盤の**単純＋造影**を全例に撮っている。

CT が答えを出す項目は5つに整理できる。

| 見る対象 | 何が決まるか |
|:--|:--|
| 腸骨・大腿動脈の内腔性狭窄と走行 | 末梢送脱血の可否、腋窩への切り替え、径による対応 |
| **右横隔膜ドームの高さ** | 開胸する肋間の選択。高位なら中心腱に糸をかけて牽引する必要 |
| 胸骨後面〜脊椎距離 | ロボット適応そのもの（[2.1節](#21-患者選択--解剖学的な線引き)） |
| **Cx（左回旋枝）と僧帽弁輪の最短距離** | 弁輪縫縮での Cx 損傷リスク（[4.6節](#46-pitfall)） |
| 胸郭変形（漏斗胸など） | 僧帽弁の展開が悪化しうる。禁忌になる場合がある |

CT を撮る価値は数字で裏づけられている。MICS 13,731例のメタ解析では
**術前CT評価群で術後脳梗塞率が有意に低く**、別の解析では
**29例に1例、CTA が重大な血管合併症を予防しうる**と推定されている。
ある単施設では有意な粥状硬化のあった28例のうち**26例（93%）が正中切開に方針変更**された。

なお術前CXRだけでも横隔膜の高さは読める。Czesla らは
「開胸の高さと肋間の決定にCXRを使う」と明記しており、CTが撮れない状況での
最低限の代替になる。

### 2.3 体位・マーキング・CO2 — ここだけが共通の型

術式を横断して共通なのは、実質2点だけである。

1. **前腋窩線を基準にマーキングする。** 大半のポートがこの線を基準に決まる。
   MMCTS の Cullen らは「原理原則はあるが、一部は*しっくりくるか*という感覚に依る。
   ただし直感は考え過ぎを招くので、症例間のばらつきを最小化するために
   標準化することが本質だ」と書いている。特に低volume施設や導入初期に効く。
2. **Veress 針で CO2 を入れてから最初のトロカールを置く。**
   胸腔内に作業空間を作ってから刺入する。圧設定は術式で異なる
   （TECAB系は 6–12 mmHg、MIDCAB では 8–10 cmH2O、最大14まで）。
   麻酔科には**必ず事前に伝える** — 緊張性気胸に類似した生理学的変化が起こる。

マーキングすべき解剖学的ランドマークは、胸骨正中線・肋間（2・3・4）・
剣状突起・下位肋骨。皮膚切開の前に印をつける。

体位は術式で反転する。僧帽弁・RAVR・ASD は**右胸**を挙上、
TECAB/MIDCAB は**左肩**にロール、心表面AFアブレーションは**左肩甲骨下**にパッドを置く。

### 2.4 ポート配置は術式別 — 共通の図は作れない

実データを術式別に並べると、共通化できない理由が明確になる。

| 術式 | 胸腔 | カメラ | 器械ポート | 作業孔 | ロボット |
|:--|:--|:--|:--|:--|:--|
| 僧帽弁（施設差あり、[4.1](#41-ポート配置)） | 右 | 3rd ICS 前腋窩線 ほか | 2nd／6th ほか | 4th ICS 3–4cm | 患者**右**側 |
| **RAVR** | 右 | **3rd ICS・作業孔の前方** | 4thの1肋間上下 | 4th ICS 3cm 肋骨温存 | 患者**左**側 |
| RA-MIDCAB | 左 | 4th ICS（乳頭やや外側） | 2nd 前腋窩線／6th | 4–12cm | 患者右側 |
| TECAB | 左 | 4th ICS | **前腋窩線上に 2nd・4th・6th** ＋剣状突起外側 or 鎖骨中線下 | 12mm service port | 患者右側 |
| ASD | 右 | 4th ICS 前腋窩線**前方** | 3rd（前腋窩線前方）／6th（**後方**） | 4th ICS | 患者右側 |
| 心表面AFアブレーション | **左** | — | 3/5/6/7/8th をマーキング、後壁は**6–7th 後腋窩線**に12mm | — | — |
| 再手術 | 右 | 癒着評価後に決定 | まず**瘢痕を避けて** 5mm を 2nd or 4th ICS | — | — |

同じ「右胸 4th ICS 作業孔」でも、**僧帽弁はロボットを患者右から、
RAVR は患者左からドッキングする**。ASD では器械ポートが前腋窩線の
前方と後方に分かれ、僧帽弁とは逆の配置になる。

したがって以降の各術式章の冒頭に、その術式専用のポート節を置く。

### 2.5 意見が分かれる点

導入を計画する際に把握しておくべき、施設間で結論が違う争点が3つある。

| 争点 | 一方の立場 | 他方の立場 |
|:--|:--|:--|
| **中等度以上のAR** | Czesla ら：心筋保護が安全に行えないので MICS 自体を選ばない | Gillinov ら：内頸静脈から冠静脈洞カテーテルを入れて逆行性を併用すれば安全に行える |
| **重症MAC** | Gillinov ら（Cleveland）：正中切開を選ぶ | Loulmet ら（NYU）：ロボットで posterior bar decalcification を行う |
| **弁＋冠動脈/大動脈弁の同時手術** | Gillinov ら：CABG併施・AVR・大動脈手術にロボットは使わない | Balkhy / Badhwar ら：RAVR を多弁治療のプラットフォームと位置づけ、弁＋CABGも行う（[第7章](#7-複合弁同時手術)） |
| **endoaortic balloon** | Czesla ら：**大動脈解離2例を経験して本法を放棄**した | STS：導入期（Phase II–III）は硬性経胸壁遮断鉗子を推奨。endoballoon は Phase IV まで待つ（内視鏡下心臓手術で**直近2年に50例以上**の経験がある施設は例外） |

いずれも「どちらが正しい」という決着はついていない。導入期には
**保守的な側（正中切開・硬性クランプ）を選ぶのが STS の推奨方向**であり、
拡大は Phase III–IV 以降とされている。

## 3. 訓練とプログラム構築

### 3.1 2つのトラックは別物 — まず選ぶ

STS 2026 コンセンサスの最初の主張は、ロボット心臓手術には
**独立した2つのトラック**があり、必要な技能も指標も異なるということである。

| | 心内トラック（弁・AF・腫瘍） | 冠動脈トラック（TECAB/MIDCAB） |
|:--|:--|:--|
| 代表術式 | 僧帽弁形成/置換、三尖弁形成、心内腫瘍切除 | LITA採取、LAD吻合、off-pump TECAB/MIDCAB |
| 人工心肺 | 多くは on-pump（末梢送脱血、短い心停止） | 多くは off-pump（または部分補助） |
| 技術の要点 | **体腔内の細かい運針**、複雑な弁形成 | 心表面の剥離、LITA採取、**動く標的への精密吻合** |
| 初期症例 | 変性弁疾患、非石灰化弁尖、末梢アクセス良好 | 孤立LAD病変、良好な標的血管、粥状硬化が軽い |
| 指導の重点 | 運針と弁形成のステップに高volumeの proctoring | LITA採取・グラフト手技・off-pump管理 |
| 主要アウトカム | 形成率、残存逆流、弁の再手術 | **グラフト開存**、標的血管再介入、正中切開への転換 |

重要な原則が1つある。ロボット遠隔操作は視野と到達性を高めるが、
**開心術・非ロボット手術の経験と技術的精度を代替しない**。
両トラックを同時に習得しようとするのではなく、
まず片方（例：MVr）で習熟を確立してからもう一方に進む。

### 3.2 Phase 0 — 始める前に満たすべき数値

STS は導入前の**最低要件**を明示している（各国の集約度により上げてよい）。

**冠動脈トラック**
- 独立した指導医レベルの心臓外科臨床 **3年以上**、および/または1年以上のロボット心臓外科フェローシップ
- 冠動脈血行再建 **通算250例**（術者として、on/off-pump 問わず）、うち **10例は OPCAB/心拍動下**
- O/E 死亡・重大合併症 **≤1**
- 非ロボット MIDCAB の経験は推奨だが必須ではない

**心内トラック**
- 独立した指導医レベルの臨床 **3年以上**、および/または1年以上のフェローシップ
- 僧帽弁形成/置換（同時手術・外科的アブレーション併施を含む）**通算75例**、
  うち **40例は直近2年以内**
- O/E 死亡・重大合併症 **≤1**
- 直近2年の一次性変性僧帽弁病変の**形成成功率 ≥80%**
- **小開胸＋末梢人工心肺の心内手術を直近2年で15例以上**（強く推奨）

**施設要件（両トラック共通）**
- 成人心臓手術 **年250例以上を3年間**
- TEE を日常的に使う**専属**の心臓麻酔科チーム
- **専属**の臨床工学（perfusion）チーム
- 高度な機械的循環補助への**即時アクセス**
- ロボットと手術器械を収容できる手術室（**約70 m²／750 sq ft**）、
  バイタル・ヘッドカメラ・ロボットカメラ・画像を同時表示できる複数モニタ
- **ロボットの使用枠：理想は週1〜2日（通常勤務時間内）、最低でも月2回**

最後の項目は見落とされやすいが決定的である。使用頻度が落ちれば
チームの技能と習熟は低下する。

### 3.3 Phase I — チーム作りとシミュレーション

Phase I の目標は術者と**チーム**のロボット操作の基礎習得である。具体的には：

- テーブルサイドの胸部準備とポート配置
- コンソール術者のメーカー固有の遠隔操作（クラッチ操作、アーム干渉の解消）
- チームでのドッキング、トラブルシューティング、保守
- **小開胸/正中切開への安全な転換のリハーサル**

シミュレーション、胸部モデル、人工組織、屍体を用いるのが有効で、
メーカーのトレーニングコーディネーターの支援も想定されている。

#### シミュレーションは何をどこまで代替するか

wet lab の学習曲線は実測されている。Atroshchenko らは
**左房閉鎖**と**内胸動脈採取**の2課題で、心臓外科の初学者と非心臓外科の初学者を比較した。
シミュレーションは「回数をこなせば必ず上手くなる」ものではなく、
課題ごとに到達までの時間と試行回数が違う。

低コストで自作できるモデルも報告されている。
AlJamal / Balkhy らは**安価で組み立てが容易なロボット心臓シミュレータ**で
内視鏡下CABGの「無制限の」練習環境を作った（proof of concept）。
Ashraf らは **da Vinci Xi 用の低コスト・高忠実度の内胸動脈採取モデル**を開発・検証している。

内視鏡下僧帽弁については、高忠実度シミュレータ上で開発された
**「運針マップ（suturing map）」**が MMCTS に公開されており、
弁輪への運針順序を標準化する教材として使える。

### 3.4 Phase II — 他施設研修と proctoring、そして最初の10例

Phase II は**peer-to-peer の臨床研修と proctoring 下の初期症例**である。
Phase III–IV に到達した施設への見学が推奨され、
コンソール術者だけでなく**テーブルサイド術者・臨床工学・麻酔・器械出し・外回り**まで
含めた研修が望ましいとされる。

見学時の観察項目はトラックで異なる。

- **冠動脈**：患者選択、麻酔準備、体位、マーキング、ポート配置、
  **肩との干渉を避けるドッキング**、非外傷的なLITA採取、
  標的血管を最適に露出する作業切開の選び方、シャント使用、
  超音波トランジットタイム流量計によるグラフト開存の記録
- **心内**：患者選択、麻酔準備、画像と実際の体格に基づく**戦略的なポート配置**のための体位とマーキング

#### STS が導入期に推奨する具体的な配置（心内トラック）

Phase II–III では以下を推奨している。これは**導入期の標準形**であり、
習熟後は施設ごとの流儀に移ってよい。

| 要素 | 位置 |
|:--|:--|
| 作業切開 | **右側方小開胸・第4肋間・前腋窩線**、soft tissue retractor 使用 |
| 第1アーム | **第3肋間、前腋窩線と鎖骨中線の間** |
| 第2アーム | カメラポート、または作業切開から直接 |
| 第3アーム | **第5肋間、鎖骨中線** |
| 第4アーム | **第6肋間、中腋窩線または前腋窩線** |
| 経胸壁遮断鉗子 | **硬性**、第3肋間の中腋窩線または前腋窩線 |
| 脱血 | 両大静脈。右内頸静脈から経皮的に、**奇静脈のレベル**でSVCに留置 |
| 心筋保護 | CPB開始後、作業切開から長い心筋保護/ベントカテーテルを上行大動脈へ |

**大腿送脱血のやり方まで指定されている**：1〜2cm の大腿動脈カットダウンで
動脈と静脈の前面のみを露出（**剥離を最小限にして術後seromaを防ぐ**）、
5-0 ポリプロピレンの purse string、TEE ガイド下の Seldinger 法。
末梢灌流カテーテルの併用は任意。

**経皮的カニュレーションと endoaortic balloon は Phase IV まで推奨されない。**
例外は、内視鏡下心臓手術で**プログラム開始前の直近2年に50例以上**の
使用経験がある施設に限られる。

proctoring は**最初の1〜5例**に特に重要とされる。ただし proctor の役割は
Phase I–II の原則の再確認、症例選択と画像の妥当性の担保、準備・カニュレーション・
ドッキング・体位の支援であり、**受け入れ側チームの能力を超える細かい術中手技の
指示は控えるべき**とされている。「チームがいる場所に合わせる」のが原則である。

**Phase II 達成の定義**：いずれかのトラックで**最初の10例**を、
プログラム開始から**6ヶ月以内**に、O/E 死亡・重大合併症 **≤1** で完了すること。

### 3.5 Phase III — 手術を「工程」に分解して計測する

Phase III は**最初の50例**を O/E ≤1 で完遂し、手術時間と術中工程が
効率化していく段階である。

ここで STS が明確に否定していることが1つある。
**総手術時間や解剖学的アウトカムだけを見ても、学習とチームの前進には不十分**である。
チームの各メンバーが別々の技能を伸ばすので、
**手術を工程に分解して各工程を経時的に追う**のが有効だとしている。

両トラック共通の計測工程（7つ）：

1. 手術台のセットアップ
2. 患者入室〜麻酔導入・各種カテーテル留置完了（wheels in → anesthesia release）
3. ロボットの清潔ドレーピング
4. 体位と体表マーキング
5. 皮膚切開〜ポート配置完了
6. ドッキング（待機位置 → テーブルサイドでのロック）
7. ポートのロック〜初期の器械配置完了・コンソール操作開始まで

#### 工程別の目標時間

**冠動脈トラック**

| 工程 | 目標 |
|:--|:--|
| LITA採取開始 → ヘパリン投与 | **<90分** |
| ヘパリン → LITA を心膜/心表面に固定 | **<15分** |
| 小開胸 → 最初の冠動脈切開（MIDCAB） | **<30分** |
| 最初の冠動脈切開 → LITA クランプ解除 | **<20分** |
| LITA クランプ解除 → 閉創完了 | **<30分** |

**心内トラック**

| 工程 | 目標 |
|:--|:--|
| 皮膚切開 → ヘパリン（心膜処理を含む） | **<90分** |
| カニュレーション開始 → 大動脈遮断（大動脈根部ベント±左室ベント留置を含む） | **<30分** |
| 最初の心房切開 → 僧帽弁の最終展開 | **<15分** |
| 最初の弁輪運針 → リング/人工弁の release 完了（弁尖の形成・切除を除く） | **<45分** |
| 心房閉鎖の第1針 → 心房閉鎖完了 | **<30分** |

重要な但し書きがある。これらは**前進を助けるために「達成可能」に設定された値**であり、
**施設は上記の半分に近づくことを目指すべき**とされている。

#### 複雑性を上げるタイミング

**各工程の時間短縮が一貫したプラトーに達してから**であり、
それは**最低20例程度**を要するとされる。

アウトカム評価は**最初の100例まで25例ごと**の区間評価が推奨され、
悪化すれば再訓練や追加 proctoring を要する。
公開報告（public reporting）も推奨されている。

アウトカムの目標値：
- **心内**：一次性変性疾患の形成率、**残存MR ≤1+、平均圧較差 ≤4 mmHg**、弁の耐久性
- **冠動脈**：術中流量評価によるグラフト開存、標的血管の再介入回避

さらに**ロボットの遮断時間とCPB時間が、自施設の正中切開の同等手術に
収束していくか**を追跡することが特に重要とされている。

臨床アウトカムに現れない微細な上達を追う手段として、
**economy of motion（動作の経済性）**の指標も挙げられている —
器械先端の総移動距離（path length）、離散的な動作数、動作の滑らかさ、
速度/時間効率、jerk（加速度の変化率）、余分な動作、力のプロファイル、
そして効率的動作の比率（rEOM）。いずれも熟練者は移動距離が短く、
動作数が少なく、滑らかで、jerk が低い。

### 3.6 Phase IV — 拡大して良い段階

Phase IV は安全性・質・手技の習熟が達成された後の最終段階で、
**最低50例**が入る条件。加えて客観的な習熟の signal として
**Phase III の目標時間を大きく上回って達成し、他のチーム時間も一貫してプラトーに達している**ことが挙げられている。

この段階で初めて拡大が推奨される術式が、そのまま本レビューの後半の章に対応する。

- 冠動脈トラック → **TECAB**（[第6章](#6-冠動脈tecab--midcab)）
- 心内トラック → **多弁（僧帽弁＋三尖弁）、多弁＋Cox maze、
  右側方経腋窩ロボット大動脈弁置換（RAVR）**（[第5章](#5-大動脈弁ravr)・[第7章](#7-複合弁同時手術)）

つまり **RAVR と複合弁は「習熟後の術式」として位置づけられている**。
導入期にこれらから始めることは推奨されていない。
