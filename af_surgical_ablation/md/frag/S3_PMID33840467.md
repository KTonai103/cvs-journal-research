- **限界**:

  **【著者記載】**（Discussion 末尾に列挙）

- **外科への含意**:

  **【原著が明示的に主張していること】**
  1. **class I 推奨があっても実装は不完全**: 僧帽弁手術＋術前AF患者の約40%が同時アブレーションを受けていない（二次引用）。本研究は、その原因を外科医側の barrier として初めて体系的に定量化した。
  2. **最大の barrier は「知識」ではなく「手術リスクの認識」**: 知識不足（class I 推奨を知らない）は 12.1%（8/66）にとどまり、機器・企業担当者へのアクセスは 98.5% が確保。一方で **cross-clamp time の延長（22.73%）と患者リスク（12.87%）が barrier の主要成分**であり、"I do not think it works" はわずか 1.50%（1名）。**すなわち「エビデンスへの不信」ではなく「目の前の症例に対するリスク回避」が律速段階**。
  3. **low-volume 僧帽弁術者ほど risk barrier を挙げる（P = .023）** → 介入は low-volume 術者への mentorship/proctoring に集中させるべき、と著者は主張。
  4. **barrier を持たない術者ほど CM-IV と LAAL を "always" 行う（P = .014）**。一方で **PVI の使用は barrier 有無で差がない** → 「barrier があるとフルの CM-IV を諦めて lesion set を縮小する」という構図が示唆される（著者は差の有無のみ記載し、この解釈は明示していない → **読み手の推論**）。
  5. **循環器/EP との連携不足が最大の介入ニーズ（21.21%）**: 紹介元循環器医が同時アブレーションに言及しないケースが 39.3%。著者は *"the formal societal recommendations are important, but these data suggest that continued education is needed even within the cardiology community"* と、**循環器側への教育の必要性**を明言。
  6. **標準化プロトコル＋教育（site visits 25.77%, videos 24.25%, proctors 24.25%）＋質指標トラッキング＋償還インセンティブ**の4本柱を実装戦略として提案。輸血プロトコル（ref 13, 14）を成功例として引用。
  7. **PVI vs biatrial maze の有効性比較データが不足していることが quality metric 設定の障害**であると著者が明記。

  **【読み手（心臓外科医）としての推論・レビューへの位置づけ】**
  8. 本論文は **アウトカム研究ではなく「なぜ Cox-Maze IV が普及しないのか」の実装研究**であり、レビューの中では「エビデンス（CTSN, STS database）と実臨床のギャップ」を説明するセクションに置くのが適切。**リズム成功率や lesion set の優劣の根拠としては引用してはならない。**
  9. Table 1-3 の値は、**「open atrial 手術（MV）でも persistent AF に CM-IV を always 行うのは 56.1% にすぎず、closed atrial（AVR/CABG）では 27.3% まで落ちる」**という、lesion set 選択の実態を示す貴重な実数データ。**closed atrial 手術での concomitant ablation こそが最大の未実装領域**である。
  10. **LAAL はすでに AF 症例でほぼ普遍的（75.8-87.9% が always）**であり、LAAOS III 以前の 2020年時点ですでに外科医の行動としては定着していた。一方 **AF既往のない症例への LAA 閉鎖は合意がない**（open で "Never" 42.4% / "Always" 18.2%）。この二極化は現在も未解決の論点。
  11. **cross-clamp time が barrier の筆頭である以上、「クランプ時間を増やさない lesion set / デバイス」（bilateral epicardial beating-heart 部分、より高速な RF/cryo、PFA の高速性）が実装を進める技術的解**であるという推論が成り立つ（**本論文は PFA に言及していないため、これは完全に読み手側の外挿**）。
  12. 著者自身が **自己申告バイアスにより実際の実施率はさらに低い可能性**を認めている点は、レビューで「実装ギャップは報告値より大きい可能性がある」と述べる根拠になる。
