2. 解剖学的基礎

2-1. Aortomitral Continuity（AMC）の構造

大動脈弁輪（後壁）
    |
    ├── 非冠尖基部
    ├── 左冠尖基部
    |
  [Intervalvular Fibrosa / AMC / Aortomitral Curtain]
    |
    ├── 右線維三角（Right / Central fibrous trigone）
    |     → 中心線維体。大きく固体的。His束が直下を走行 → **完全房室ブロックリスク**
    |
    ├── 左線維三角（Left / Lateral fibrous trigone）
    |     → 心室側壁筋・僧帽弁輪・大動脈弁輪を三角形に連結

    |
  僧帽弁前尖（AML）基部 ← IVF = 僧帽弁周径の前方 1/3
    |
  後方筋性弁輪 ← 残りの 2/3（三角間距離）

AML coaptation zone 腱索付着部 hemi-Commando では温存

2-2. IVF 破壊の病態メカニズム

  1. 人工弁縫合輪への Biofilm 形成 → 感染 → 酵素的組織破壊
  2. 膿瘍が IVF を侵食 → 両弁輪間の線維性骨格が崩壊
  3. 傍弁輪漏（PVL）→ 空洞性欠損 → 両弁輪破壊 の順に進行
  4. 重篤な心不全・敗血症性多臓器不全へ
疫学
  • Cleveland Clinic でのDVR適応 IE の約 36% にIVF浸潤を認める（Navia 2019）
  • 大動脈 + 僧帽弁合併 IE の 69% が浸潤性（Hussain 2014）
  • 根部膿瘍を有するIE の 25% に続発性 MV 感染（SMVD）が発生（Siniawski 2005）

3. 適応

3-1. 主適応：感染性心内膜炎（IE）

Commando の絶対的適応

IVF/AMC 破壊を伴う浸潤性 IE → Commando（またはhemi-Commando）以外に根治的治療の選択肢なし

手術適応の基準（AATS 2016 ガイドライン）：

適応 推奨強度
弁機能不全による心不全症状 Class I（LOE B）
左心系 IE で起因菌が S. aureus・真菌・高度耐性菌 Class I（LOE B）
房室ブロック・弁輪部/大動脈膿瘍・破壊性穿通性病変を合併 Class I（LOE B）
適切な抗菌薬 5〜7 日後も持続する菌血症・発熱（persistent infection） Class I（LOE B）
PVE で再燃（適切な抗菌薬完遂・血液培養陰性化後の菌血症再発、他に感染源なし） Class IIa（LOE C）
適切な抗菌薬にもかかわらず塞栓を繰り返し疣贅が遺残 Class IIa（LOE B）
NVE / PVE で可動性疣贅 >10 mm ＋ 塞栓の臨床所見 Class IIb（LOE B）

出典: Pettersson_AATSGuidelinesIESurgery_AnnCardiothoracSurg_2019（AATS 2016 Figure 2）

推奨クラスの読み違いに注意

「PVE だから Class I」ではない。 Class I が与えられているのは S. aureus／真菌／耐性菌、膿瘍・房室ブロック・穿通性病変、心不全、持続感染の 4 項目であり、 PVE 単独は「再燃例で Class IIa」、可動性疣贅 >10 mm は「塞栓所見を伴って Class IIb」にとどまる。 Commando の対象となる 弁輪部膿瘍・穿通性病変は Class I に含まれるため、適応そのものは強い。

Commandoが必要となる所見（術前画像・術中確認）：

  • TEE / CT で確認：AMC の膿瘍形成・空洞性欠損・瘻孔
  • 大動脈弁輪破壊が非冠尖〜左冠尖交連を越えてAMLに及ぶ
  • 大動脈根部膿瘍 + IVF浸潤（周囲組織の高輝度・壁肥厚・エコーによる膿瘍洞確認）

4. 術式の分類と適応判断

4-1. 術式選択アルゴリズム

IVF/AMC 浸潤 IE （または非IE）
        |
        ├── 大動脈根部置換が必要か？
        |       ├── Yes → ROOT-Commando (or ROOT-hemi-Commando)
        |       └── No → ↓
        |
        ├── AML のみ罹患（後尖・腱索・後方弁輪は温存可能）？
        |       ├── Yes → hemi-Commando（MV repair + AVR + homograft IVF再建）
        |       └── No（後尖・腱索・後方弁輪にも波及） → Full Commando（DVR + IVF再建）
        |
        ├── 後方 AV groove も破壊？
        |       └── Yes → Commando + posterior AV groove reconstruction（追加）
最終判断は術中所見による

術前 TEE/CT で計画するが、根治的デブリードマン後の術中所見で最終決定。 hemi-Commando を計画していても、腱索・後尖の浸潤が発覚すれば Full Commando に切り替える。

術式 適応 特徴 主な成績

検査 目的 優先度

5-2. 手術タイミング（AATS 2016 推奨）

核心原則

「手術適応が確立したら遅延しない（operate as soon as possible）」 心不全の発症を待つ必要はない。浸潤性 S.aureus PVE・早期 PVE は特に早期手術。

状況 推奨
適応確立後 数日以内（within days）に手術（Class I, LOE B）
塞栓の切迫リスクが高い大型可動性疣贅 48 時間以内の緊急手術が妥当（Class IIa, LOE B）
浸潤性 S.aureus IE / PVE 緊急/準緊急手術
脳卒中・神経症状合併例 手術の必要性と脳梗塞拡大・頭蓋内出血のリスクを 秤にかけて決定（Class IIa, LOE B）。頭蓋内出血既往例は 3 週以上の待機が妥当（Class IIa）
非複雑性・非 Staph・後期 PVE 抗菌薬で試みるが再発多い → 継続モニタリング
「24〜48時間以内」は全例の推奨ではない

AATS 2016 の Class I は「適応確立後 数日以内」であり、48 時間以内が推奨（Class IIa）されるのは 「塞栓の切迫リスクが高い大型可動性疣贅」に限られる。下掲の推奨表で該当行を確認できる。

6. 手術手技（Step-by-Step）

Step 1：体外循環確立・心臓アクセス

項目 標準 再手術 / 注意要
皮膚切開 正中胸骨切開 末梢カニュレーション（腋窩動脈）先行 → 胸骨切開
カニュレーション 大動脈 + 二心房（bicaval） 大腿静脈 + 大腿/腋窩動脈も選択肢
心筋保護 順行性 + 逆行性 逆行性：冠状静脈洞へ 8F 自己膨張バルーン付きカニュラを直接挿入
体温 中等度低体温（28〜32℃） —
SVC 横断切離 Commando 群 44%（Pettersson 2014） 僧帽弁へのアクセス拡大のため積極的に施行

心臓切開の順序（標準的）：

  1. 斜方大動脈切開（右冠動脈起始部より ≥1cm 頭側）
  2. 非冠尖〜左冠尖交連付近で IVF を切開し僧帽弁へのアクセス路を形成
  3. 左房天蓋（LA roof）への切開延長 → 左房を開放
  4. 必要に応じ心房中隔切開で露出を追加

Step 2：感染巣の評価（術中マッピング）

  • TEE 所見と術中所見を照合
  • 膿瘍の位置・範囲・深さを確認
  • His束（右線維三角直下）との位置関係 → 完全 AVB リスク評価
  • 左回旋枝との位置関係（左線維三角側の縫合時）
  • 感染範囲が後方弁輪・右室・後方 AV groove に及ぶか確認

Step 3：Radical Debridement（根治的デブリードマン）

Commando 成功の大前提

正常組織が露出するまで感染・壊死組織・縫合糸・異物をすべて除去する。 不十分なデブリードマンは再発 IE の最大原因。

手順：

  1. 大動脈弁（人工弁の場合 → 縫合糸を含むすべての異物を除去）
  2. 大動脈根部のデブリードマン（膿瘍腔を開放・洗浄）
  3. IVF 感染組織の切除（AML の近位帯状ゾーンを含む）
  4. 僧帽弁（人工弁 → 縫合糸完全除去、弁輪を undermine しない）
  5. 各ステップ後に豊富な生理食塩水洗浄を繰り返す
  6. Barcelona 法：非希釈ポビドンヨード（原液）でデブリードマン面を清拭（Forteza 2025）
hemi-Commando でのデブリードマンの特則

AML は近位帯状ゾーン（proximal clear zone）を IVF と一体で切除し、 AML 遊離縁（coaptation zone）= 一次・二次腱索付着部は温存する。

Step 4：AMC / IVF 再建（Commando の核心）

パッチ素材の選択

素材 特徴 推奨シナリオ
大動脈同種移植片（Aortomitral Allograft） 抗菌特性・感染再発リスク低・止血容易 Cleveland Clinic 第1選択（特に MRSA・広汎破壊）
グルタルアルデヒド固定ウシ心膜（第2選択） 入手容易・広く使用 Barcelona 法標準（折りたたんで二重層使用）
自己心膜（第3選択） 最も生体適合性が高い 初回手術・癒着が少ない例
Dacronパッチ 代替素材 Elgharably 2018 でn=1補填に使用
自己左房組織 パッチ不使用変法 Yajima 2022（再手術で自己心膜利用不可の場合）
Equine pericardial strip Pledget 代替に使用 Aphram 2021 Brussels 法（異物量最小化）

標準ダブルレイヤーパッチ法（Cleveland Clinic）

  • パッチを十分なサイズ（generous）で裁断（過小は最大の危険）
  • 下葉（lower leaf）：左房天蓋の閉鎖に使用
  • 上葉（upper leaf）：大動脈根部（IVF）の再建に使用
  • パッチの両端を両線維三角（右・左）にアンカリング
  • 各三角での縫合を Prolene 連続縫合で確保し、独立した結節縫合でブロック（Barcelona 法）

縫合アンカリングの詳細

僧帽弁側（後方筋性弁輪 = 2/3）：

  • Pledget付き水平マットレス縫合を心室側から
  • 筋肉組織にしっかりと固定（左回旋枝注意）

僧帽弁側（前方 = IVF側 1/3）：

  • 再建 IVF パッチの縫合糸が人工弁縫合輪を貫通し大動脈弁側へ続く
  • MVP縫合輪に過度の張力がかからない弁を選択（柔軟な縫合輪の弁が重要）

Barcelona 法の補強点：

  • 各線維三角での連続縫合終了後に独立した 3-0 Prolene 結節縫合で追加補強（Forteza 2025）

Step 5：僧帽弁置換（MVR）—— AVR より先に施行

手術順序は重要

MVR → IVF 再建（パッチ固定） → AVR の順 逆順（AVR先）は術野が狭くなり IVF 再建が困難になる

  • 後方弁輪（三角間）：Pledget 付きマットレス縫合（心室側から）
  • 前方 1/3（IVF 側）：IVF パッチ縫合糸が MVP 縫合輪を貫通
  • 弁種：生体弁 90%（Cleveland Clinic 標準、感染耐性・心房細動リスク配慮）

Step 6：大動脈弁置換（AVR）

  • MVR・IVF 再建の後に施行
  • 再建した IVF パッチ前翼 + 大動脈弁輪に縫合
  • 根部置換が必要な場合（ROOT-Commando）：コンジット選択あり（→ Section 7参照）
  • Stentless 弁（Freestyle 等）は不整形の再建 LVOT に適合しやすい

Step 7：残存死腔の処理・洗浄・閉鎖

  • 膿瘍腔の残存死腔を最小化（充填縫合・閉鎖）
  • 豊富な生理食塩水洗浄 を繰り返す
  • 左房：パッチ下葉で閉鎖
  • 一部施設では抗菌薬含浸ビーズ/スポンジを死腔に充填

Step 8：体外循環離脱前の止血確認

離脱前止血確認は完璧に

体外循環離脱後は lateral trigone 再建部への外科的アクセスが不可能。 離脱前に圧迫止血・追加縫合を完全に済ませること（Pettersson 2014）。

7. 重要解剖学的ポイントとPitfalls

7-1. ★最重要 Pitfall：Lateral Trigone（左線維三角）の無張力再建

Pitfall #1 — 左線維三角の張力（最重要）

Pettersson 2014 が明示した最重要 Pitfall： 左線維三角（lateral trigone）に張力がかかると離脱後に出血・修復不能な弁離開が生じる。

無張力再建の 3条件（すべて必須）：

  1. MVP が心室筋に確実に固定されていること
  2. 再建 IVF + 左線維三角が心室側壁筋から大動脈弁輪まで無張力で固定されていること
  3. AVP が再建 IVF パッチに確実に縫合されていること

→ 離脱後は修復不能 → 離脱前の完璧な止血・固定が必須

7-2. Pitfalls 一覧

# Pitfall 内容 対策
1 Lateral trigone 張力 離脱後アクセス不能な出血源 無張力再建の 3条件を満たす（上記）
2 不十分なデブリードマン 感染残存 → 再発IE（最多の長期失敗原因） 正常組織露出まで徹底除去
3 パッチサイズ不足 パッチが小さすぎると張力がかかる Generous size で裁断（余裕のあるサイズ）
4 完全房室ブロック（AVB） 右線維三角・His束への操作 縫合位置の確認。PM 挿入率 20-30%（ROOT群 30%）
5 左回旋枝損傷 左線維三角〜後方弁輪縫合時 針の深さ・位置確認。TEEで確認
6 LVOT 閉塞（hemi-Commando でのSAM） Homograft AML の過可動 不完全弁輪形成術リング植込み（施行率36%、Elgharably 2018）
7 遅発性MR（hemi-Commando） パッチ/homograft AML の収縮・線維化 定期的な術後 Echo フォロー
8 再手術時の出血（胸骨切開） 仮性動脈瘤・グラフトが胸骨に癒着 末梢カニュレーション先行 + 慎重な剥離
9 SVC 損傷 露出拡大のための SVC 横断切離時 計画的に行えば安全（44% で施行、Pettersson 2014）
10 弁間干渉（Root-Commando） AV + MV 人工弁の機械葉が干渉 通常の DVR コンジットを避け、自家組立コンジット or 単独弁を使用（Pechenenko 2023）
11 冠動脈再吻合困難（en bloc変法） 根部一塊切除後の冠動脈ボタン位置 冠動脈ボタン先行移動を最初に行う（Aphram 2021）
12 PPM（小弁輪化） patch-sparing 法でのMVP ワンサイズダウン LVOT サイジング評価 + PPM 許容判断

8. 弁選択

8-1. 大動脈弁の選択

弁種 メリット デメリット 推奨シナリオ
大動脈同種移植片（Homograft） 抗菌特性・感染再発リスク低・止血容易・不整形弁輪への適合性 10年以降に構造的劣化・再手術率増加、入手性問題 MRSA感染・広汎弁輪破壊・根部感染（Cleveland Clinic 第1選択）
生体弁（Bioprosthesis） 入手容易・抗凝固不要 耐久性（特に若年者） 標準選択
Stentless 生体弁（Freestyle等） 不整形再建 LVOT への適合性・血行動態良好 縫合技術要求 Root-Commando後の非円形弁輪
機械弁 長期耐久性 抗凝固療法・感染環境では問題あり 相対的に推奨されにくい。頭蓋内出血・広範な脳梗塞を有する例、および重症で術後経過の遷延が予想される例では機械弁を避けるべき（AATS Class I, LOE C）
弁種選択のエビデンス（Jassar et al., Yi 2025 レビューより）

弁種（Homograft vs 生体弁 vs 機械弁）による感染再発率・死亡率・合併症発生率は同等。 弁選択は術者・施設経験・患者背景（年齢・抗凝固リスク・MRSA感染）に基づき個別化する。

原典図：弁種と感染再発——同種移植片は有利か

8-2. 僧帽弁の選択

選択 適応
生体弁（多くの場合90%以上） Full Commando での標準。AF合併・抗凝固リスク例
機械弁 若年者・長期耐久性要求
弁修復（hemi-Commando） 後尖・腱索温存可能例 → LV 収縮機能維持に有利

9. 技術的変法（Modifications）

9-1. hemi-Commando（確立した主要変法）

適応（3条件すべて必要）：

  1. 大動脈根部置換を要する病変（根部膿瘍・瘻孔）
  2. IVF + AML の浸潤（組織肥厚・膿瘍との交通）
  3. MR が AML 病変のみ → 後尖・腱索・後方弁輪は温存可能

手技のポイント：

  • Aortomitral homograft の AML を trimmed して native AML 遊離縁に 3-0 Prolene 連続縫合
  • Bovine pericardium strip で近位縫合線を補強（組織脆弱への対策）
  • 不完全弁輪形成術リング（三角間）で AML 過可動・SAM を防止（施行率36%）
  • 左房天蓋を心膜パッチで閉鎖

参照: Elgharably_HemiCommandoHomograftDVE_EJCTS_2018 Navia_HemiCommandoProcedure_JTCVSTech_2023 MarinCuartas_HemiCommandoLeipzig_EJCTS_2023

原典図：hemi-Commando の手技

模式図（Cleveland Clinic 公式）→ 術中写真 → 変法（Leipzig）→ 原型論文（2010）の順に並べた。

9-2. Root-Commando（根部置換を伴う変法）

適応： 感染が大動脈弁輪の他の部位（非冠尖・左冠尖交連以外）に浸潤、または大動脈根部疾患自体が置換適応。

根部置換の選択肢：

オプション 特徴
Human allograft 感染耐性最良・長期耐久性（第1選択）
Medtronic Freestyle（豚大動脈根部） 入手可能施設限定
市販生体弁 conduit 不整形環への適合性に課題
自家組立コンジット（Pechenenko 2023） 緊急時・入手困難時の代替（23mm 機械弁 + 26mm Hemashield）

成績（Forteza 2025, Barcelona）： ROOT vs non-ROOT Commando で院内死亡・中期生存に有意差なし（共に 1年76%、5年67%）。

参照: FortezaGil_CommandoVariantsIntervalvularFibrosa_EJCTS_2025 Pechenenko_RootCommandoModifiedConduit_MMCTS_2023 Nosaka_EmergencyRootCommando_ICVTS_2024

9-3. En Bloc Root Resection + Commando（Brussels 変法、Aphram 2021）

特徴：

  • 冠動脈ボタンを先行移動 → 大動脈根部を感染人工弁・炎症組織ごと一塊で切除
  • Equine pericardial strip を Pledget の代替として使用 → 異物量を最小化
  • Stentless 生体弁（Freestyle）を使用

メリット： 再手術での感染組織の確実な一括除去が可能

参照: Aphram_EnBlocRootCommandoBrussels_JTCVSTech_2021

原典図：En bloc 根部切除（Brussels 変法）

9-4. Patch-Sparing 変法（Yajima 2022）

適応： 再手術で自己心膜が利用不可な場合（高度癒着・多回手術）

手技： 残存健常左房壁 + 大動脈基部組織の走行縫合のみで AMC を再建。人工パッチ不使用。

注意点： MVP をワンサイズ小さく選択（張力軽減のため） → PPM リスクは個別評価

参照: Yajima_PatchSparingAMCReconstruction_EJCTS_2022

原典図：Patch-sparing 変法（Yajima 2022）

9-5. Aorto-Annulo-Septotomy 変法（Matsuzaki 2024, 日本）

特徴： 左房天蓋切開を省略し、卵円窩から垂直に心房中隔を切開して露出。複合パッチ（ポリエステル + ウシ心膜）で同時弁置換・IVF再建。

禁忌： 冠状静脈洞膿瘍

参照: Matsuzaki_ModifiedCommandoAortoAnnuloSeptotomy_ICVTS_2024

原典図：Aorto-annulo-septotomy 変法（Matsuzaki 2024）

9-6. Chimney Commando（Yang 変法）

特徴： 小弁輪 + PPM の解決策。外科医が組み立てた Valved Conduit を使用。ポリエステルグラフトに弁を収納し、僧帽弁輪の 3/4 を Conduit で固定、残余 1/4 をウシ心膜パッチで IVF 再建。

メリット： LVOT 閉塞リスクを最小化しながら弁輪拡大を実現（30mm 超の弁輪拡大も可能）

参照: Yi 2025（Yi_CommandoProcedureNarrativeReview_GenThoracCardiovascSurg_2025）

原典図：Chimney Commando と弁輪拡大への応用

9-7. Posterior AV Groove 再建追加変法（Pechenenko 2023）

適応： 後方 AV groove にまで感染・組織破壊が及ぶ症例（前回手術歴 + 高度 MAC + 再建歴）

参照: Pechenenko_CommandoPosteriorAVGroove_MMCTS_2023

11. 術後管理

11-1. 抗菌薬

  • 感受性が判明している有効な抗菌薬を投与（術前から継続）
  • 術中培養と感受性が判明した時点で レジメンと期間を再検討・決定（AATS Class I, LOE B）
  • 活動性 IE 術後の標準静注期間は 6 週間。起算日は 手術日であり、術前投与期間は算入しない（AATS Class IIa, LOE B）。起因菌・治療反応・病理所見に応じて調整
  • 真菌性 IE では生涯にわたる経口抑制療法が妥当（AATS Class IIa, LOE B）
  • 術後管理は感染症専門チーム（Endocarditis Team）との連携が必須

11-2. ペースメーカー（AVB 対策）

完全 AVB リスク
  • ペースメーカー植込み率： 20-30%（Forteza 2025：non-ROOT 20.8%、ROOT 30.0%）
  • Kim 2013（Samsung）：完全 AVB 3例（n=30、10%）
  • 術後 ECG モニタリングを継続し、早期 PM 判断

11-3. 術後エコー評価

評価項目 目的
IVF 再建の完全性（paravalvular leak） 弁離開・異常交通の確認
LV 収縮機能（LVEF） 特に hemi-Commando 後（腱索温存効果の確認）
大動脈弁 mean PG 弁輪拡大効果の確認
僧帽弁 mean PG / MR 弁機能評価
LVOT 血流パターン LVOT 閉塞・SAM の除外
Post-Commando 解剖（Simpson 2023）

Commando 後の解剖的変化は将来の VIV-TAVI / TMVR 計画に影響する。 使用パッチ長・弁の位置情報を記録しておくことが重要。

12. 特殊シナリオ

12-1. 緊急・準緊急 Commando

原則： 手術適応確立後は遅延しない（AATS 2016）

実績：

  • Nosaka 2024（石川県立中央病院）：IE + Valsalva 洞慢性解離性動脈瘤 → 緊急 Root-Commando で救命
  • Rheault-Henry 2025（Western Univ, Canada）：急性 IE + 広汎双弁破壊 → 緊急 hemi-Commando 成功
Info

緊急時でも Commando / hemi-Commando は施行可能であることが複数例で示されている。

原典図：緊急 Root-Commando の症例

12-2. 再手術（Redo）での Commando

注意点：

  1. 末梢カニュレーション先行（大動脈・仮性動脈瘤が胸骨に接触する場合）
  2. SVC 横断切離（露出確保。Pettersson 2014 で 44% に施行）
  3. 自己心膜が使用不可 → patch-sparing 法（Yajima 2022）または代替素材
  4. Cabrol 変法併用（periaortic → 右房シャント）で後方出血コントロール（Kim 2025）

12-3. TAVR-IE → Commando

増加する新適応シナリオ：

  1. TAVR IE（E.faecalis、S.aureus 等）が AMC に浸潤
  2. TAVR デバイス Explant + IVF 再建（Commando）の必要性

技術的注意点：

  • TAVR device の残存スカートと組織との癒着
  • 冠動脈入口部への影響（低位留置の TAVR）
  • 術後の VIV 解剖計画への影響

参照: Shea_CommandoDoubleValveEndocarditis_JTCVSTech_2023, Jarral_TAVREndocarditisCommandoProcedure_JTCVSTech_2024, Simpson_TAVRExplantAortomitralReconstruction_AnnCardiothoracSurg_2025

原典図：TAVR-IE に対する Commando

12-4. 機械双弁 IE → Commando

  • 最も困難なシナリオの一つ
  • 機械弁の縫合糸・人工材料をすべて除去してからのデブリードマン
  • Rifampin 溶液浸漬や Equine pericardial strip の活用で感染再発リスクを低減
  • 参照: Mouritane_CommandoMechanicalDVPEndocarditis_MMCTS_2024

13. 将来展望

13-1. 未解決課題

  1. 死亡率・再発率・再手術率の長期データ（RCT なし、多施設前向きコホート少ない）
  2. リスク層別化ツール（CPB 時間・LVEF・大動脈病態の統合スコア）
  3. TAVR-IE 急増への対応（標準化された手技・アルゴリズムの確立）
  4. hemi-Commando の遅発 MR 問題（homograft AML の収縮・線維化）

13-2. 技術的将来方向

  1. パッチ配置最適化（手術時間短縮・出血リスク低減）
  2. 3D 印刷モデルによる術前計画（IVF 破壊の空間的理解）
  3. ECM（細胞外マトリックス）スキャフォールド（生体材料の代替）
  4. Commando 原則の拡大応用（弁輪拡大・TAVI 後の structural failure 管理）
