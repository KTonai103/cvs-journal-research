# 第3章　術式② Free-standing full root ＋ 補強（RR+R）

最も広く行われている系統である。基部ごと入れ替えたうえで、**弁輪・洞・STJの3レベルを個別に補強する**。以下、施設ごとに「何をどこまで補強するか」が驚くほど違うことが見えてくる。共通しているのは**「基部をfree-standingのまま放置しない」**という一点だけである。

## 3-1. Mount Sinai式 tailored total root（Williams & El-Hamamsy）

1. 大動脈を**STJの5mm遠位**で切開する
2. **無冠洞と左-右交連のnative組織は温存する**（後で外部支持に使うため）→ **露出のために無冠洞を切り開かない**
3. autograftは**top-down**で採取、右PA起始の3〜5mm近位から
4. 漏斗部筋は**2〜3mm残してトリム**
5. **結節4-0 prolene**で**弁輪下（subannular）に深く**留置。**針は大動脈弁輪の1mm上から入れ2〜3mm下に出す**。autograft側は肺動脈弁尖のhinge pointから上向きに通し、薄い漏斗部筋を縫合線から除外する
6. **neo-commissureを大動脈弁輪レベルで120°対称に**配置する
7. 冠動脈ボタンは各洞の中央、**STJより下**に
8. 大動脈吻合を完成させる前に**≥28mmの大型肺動脈homograft**を植込む（遠位5-0、近位4-0で、**心室中隔は部分層で刺して中隔枝を避ける**）
9. **交連上のPA余剰を切除し、交連の2〜3mm上まで**とする
10. **上行大動脈≥38mm、またはautograft STJと上行大動脈のmismatch → 26 or 28mm Dacron interposition graft**
11. **CPB離脱・プロタミン後**に、温存した無冠洞と左-右交連のnative組織をinterposition graftにtackし、**非拘束的（non-constraining）な外部支持**とする

**成績**：2010年以降>500例、手術死亡2例（0.4%）で**両方とも最初の100例内**。退院時平均圧較差4mmHg。10年まで基部径・弁機能は安定。

> [!tip] 手順11がこの術式の思想を体現している
> 補強を**プロタミン後に**行う点が重要である。CPB下の萎んだ基部で補強を決めると、拍動下の実寸と合わない。かつ「tack（留めつける）」であって「wrap（包む）」ではない。**native組織を、拘束せずに添えるだけ**。これが「dynamismを保つ」という主張の実装である。

## 3-2. 同じMount Sinaiのもう一つの系譜（Stelzer, 702例・1987–2019）

同一施設でも Stelzer の補強の考え方は異なり、**フェルトを使う**。

- 当初から**測ったフェルトストリップでneo-aortic弁輪を拘束**する
- 中期以降**2本目のフェルトストリップをSTJ安定化に追加**
- 洞部は可能な限り残存native大動脈壁で支持
- homograftは**10%オーバーサイズ**。2008年以降**>99%が脱細胞化**
- **上行大動脈は>5cmで置換、それ未満の拡大はaortoplastyで縮小。目標は<3.5cm**
- **全縫合線が連続縫合**。心膜上部を大血管の上で可能な限り閉鎖する（再開胸を容易にするため）
- 抗線溶薬をルーチン、**acute normovolemic hemodilution**をルーチン化
- **SBP<110 mmHgを、特に最初の24〜48時間、厳格に**

**成績（702例）**：手術死亡 **7例（1%）**、合併症 6.6%。

| | simple群（419例, 59.7%） | complex群（283例, 40.3%） |
|---|---|---|
| 定義 | 既往開胸なし＋軽微な同時手技のみ | 既往開胸あり and/or 上行置換・僧帽弁形成等 |
| 手術死亡 | **0.7%** | **1.4%** |
| 合併症 | 4.8% | 9.2% |

そして**時系列でみるとsimple症例は減り、complex比率は34%→48%に増えたにもかかわらず、死亡率は下がった**。

> [!success] 「適応拡大と成績向上は両立しうる」ことを示す最良のデータ
> Ross手術の適応を広げる議論では必ず「難しい症例に手を出すと成績が落ちる」という反論が出る。Stelzerの702例は、**同一術者・同一施設で、症例の難度が上がりながら死亡率が下がった**という反例である。ラーニングカーブ（第9章）と読み合わせるべき。

## 3-3. Stuttgart式 reinforced FRT（Liebrich, 832例・25年）

- 漏斗部筋を**3〜4mm残し**、Hegarでサイズ計測
- **3本のproleneを大動脈弁輪の各nadirとautograftの対応nadirに置いて固定** → 近位吻合は**nadir間の連続縫合**
- **FRT＋AR群では近位縫合線にDacronストリップを織り込み、さらに大動脈壁remnantからautograftへ2本目の縫合線を作って弁輪を安定化**する
- CPB 172分、遮断137分。30日死亡 0.96%（8例）。補強あり73%／なし27%

**成績（832例）**：累積生存は **5年 97%（95%CI 95–98）／15年 92%（90–94）／20年 86%（82–90）**。Ross関連再手術137例、初回再手術までの中央値8.2年、**再手術の病院死亡は1.1%**。

> [!warning] 数値の齟齬（本レビューでの扱い）
> Liebrich論文の**Abstractは「20年生存92%」**と書いているが、**Results本文は「15年92%／20年86%」**である。Abstractの数値は15年値の誤記と判断し、**本レビューではResults本文（20年86%）を採用する**。

### Liebrichが明示した4つのpitfallと3つのcaution

**pitfall**

1. **左主幹・第1中隔枝の損傷** → #15刀で後方RVOT心内膜を弁輪の5〜8mm下に切開する
2. **近位「補強」縫合線、とくに弁輪安定化のための2本目の縫合線での深すぎる刺入によるautograft弁尖損傷** ← 補強そのものが弁尖を傷つけるという、補強派にとって最も痛い指摘
3. **RV-PA connectionのkinking** — autograftに対して導管を長く残しすぎると、心臓が血液で満たされた時に遠位吻合部が折れる

**caution**

1. **autograft拡大の回避** ＝ 近位吻合の補強 ＋ autograftを短く保つ ＋ 遠位（neo-STJ）安定化のための上行大動脈Dacron置換
2. **autograft逆流の回避** ＝ malalignment/distortionのない縫着。解剖学的にやむを得ない場合は**冠尖のcommissural plicationによる2〜3mmの「軽度oversizing」**
3. **autograft床からの出血** ＝ 冠静脈洞逆行性灌流で出血点を可視化してから低出力電気メス

## 3-4. Aswan式 loose jacket（Afifi & Yacoub）

「native大動脈壁でautograftに緩いジャケットを着せる」という発想。

1. 上行大動脈を**中央（交連の約2cm上）で完全に離断** → 近位大動脈を**無冠洞のnadir直上まで縦切開**する
2. 採取：**筋カフ2〜4mm**、遠位は**交連の2〜3mm上**
3. 縫着：**すべての針を、大動脈側では弁輪の直下に、肺動脈側では肺動脈弁輪を含めて通し、肺動脈基部を大動脈弁輪の「中に埋める」**
4. 冠動脈ボタンは**大動脈壁に残した孔を通してautograft洞に到達**させる。**十字切開で孔を広げてkinkを防ぐ**
5. **loose jacket**：**涙滴型の新鮮心膜**で無冠洞切開を閉鎖しつつやや拡大 → autograft周囲にnative大動脈壁の筒ができる。**ジャケット上端を頭側に持ち上げて遠位大動脈吻合部を覆い、4〜5本の結節縫合で固定する**

手順5の最後の一手（ジャケット上端を吻合部の上まで持ち上げる）は、**autograft上方のnative大動脈の遅発性拡大を防ぐための必須手順**として明記されている。「洞だけ包んで満足する」と、その頭側が拡大する。

## 3-5. Homburg式 suture annuloplasty ＋ simplified root wrapping（Matsushima & Schäfers）

補強を「糸1本」で済ませる、最も人工物の少ない解。

- **弁輪径>25mmで外部suture annuloplastyを発動**する
- autograftを**左室内に反転させて弁輪内（intra-annular）に連続4-0で縫着** → 引き戻して縫合線を目視確認し、必要なら追加縫合する
- **ePTFE（Gore-Tex CV-0）の走らせ方**：一方の針は右-左尖間交連の外側の中隔筋から入れ、基部弁輪の後方周をまわってaortomitral continuityへ。他方の針は右尖nadir外側の右室心筋を前方に通し、**膜性中隔の領域では大動脈の外側に出したまま**、無冠尖nadir外側の大動脈外膜を接線方向に通す
- **BSAでHegarを選んで結紮する（BSA<1.8 m² → 21mm、≥1.8 m² → 23mm）**
- 上行大動脈>30mmならDacron置換（BSA<1.8 → 24mm、≥1.8 → 26mm）
- **simplified root wrapping**：autograft遠位吻合に**大動脈基部組織のtongue（交連部）を巻き込む** → **10〜15mm幅のnative基部壁がautograftの3交連の外側に残る**
- 15例で再手術・拡大・AIなし

> [!important] Homburgのサイジングは「autograftを測らない」
> ePTFEを結紮するHegar径は**患者BSAだけで決まる（21 or 23mm）**。autograftの実測径は参照しない。これは第5章のサイジング論争で「患者体格派」の最も純粋な形である。Mount Sinai（肺動脈弁輪径＋8−2mm）と真逆の設計思想であることに注意（第11章 対立点#3）。

## 3-6. MGH式 — 「測って印をつける」full root（Nam & Bloom）

柔らかいautograftを幾何学的に扱うための、最も体系化された手順。

1. autograftを**反転させてHegar/graduated cone上に載せ、3尖の交連とnadirを全てマーキングして対称性をconeで評価**する
2. autograftを戻して長さを測る（通常約4cm）＝ **そのまま planned homograft length になる**
3. **coneでLVOT内に60°間隔の基準マーキング**を作る
4. annuloplastyを要する場合は、**60°マーキングの全点に6本のpledgeted糸**を置き、**目標弁輪径より5〜6mm大きいDacron graftのsewing ringに通して、実測autograft径のHegar上で結紮**する
5. 縫着の順序：右尖nadirから開始し、autograft側は外→内、LVOT側は内→外で深く。右-左交連へ向かい、次に左洞、autograftを術者の反対側に移して右洞の残り、最後に無冠洞
6. **原則：crown状の外科的弁輪ではなく、basal ringレベルの平面的な留置**

## 3-7. Florida sleeve Ross（Spindel, Ochsner）— 「簡便な補強」

David手術のFlorida sleeve法をRossに転用したもの。**弁輪・洞・STJの3レベルを1本のbulged graftで同時に押さえる**。

1. 3洞すべてを切除し、**弁輪上5mmの大動脈壁を残す**
2. **同一水平面に6本のpledgeted subannular縫合**（各nadir下と各交連下に1本ずつ）
3. **bulged root graftのサイズ ＝ Mosaic valve sizerで測ったautograft弁輪径 ＋3mm**（PA壁厚分）
4. graftを**1/6ずつマーキングし、縦に二分**する
5. autograft近位吻合を先に完成させる → **6本中5本をgraftに通してparachute・結紮**
6. 冠動脈用のスリットを作りボタン再建 → 上行大動脈置換
7. **遮断解除後、無冠尖nadirの6本目をTEEガイド下に結紮する**（＝これがannuloplastyのきつさを決める）
8. 二分したgraftを緩く結節縫合で寄せ、遠位を上行graftにtackする。**この緩さが早期の拍動ごとの血行動態変化へのcompliancyになる**

## 3-8. Ross-PEARS（Vienna / London）— 患者個別の外部メッシュ

**手技（Conci, MMCTS 2023 / Redondo, JTCVS Tech 2024）**

- 術前CTから患者個別の3Dプリント鋳型で**メッシュ製の外部支持prosthesis**を作製する。**サイズは肺動脈径の115%**（Vienna）。**製作に約3週間**
- prosthesisの**近位hemを3本の等間隔prolene糸でマーク**（＝3つの弁交連に対応）し、軸方向の縫い目を開いておく
- **autograftをinvagination techniqueで大動脈弁輪に縫着する。連続4-0で、autograftとPEARS graftのhemを同時に取り込む** → これで弁輪が完全に補強される
- 冠動脈ボタンは**PEARS graftの後方と前方左寄りの洞に開けた2つの窓**を通して再建する
- **上行大動脈とautograftの径差が大きい場合はreduction aortoplasty**（Redondoの50例中**44%**が必要だった）
- CPB離脱・止血後に**PEARSを大動脈の周りに巻いて、非冠動脈側で縦の軸縫い目を結節Ti-Cron糸で閉じる**。**autograftと上行大動脈の全長を覆うことが望ましく、reduction aortoplasty後は特にそうである**
- Viennaでは**腕頭動脈まで**包む

**他の補強との差別化（3点）**
① 患者個別で幾何学を保つ　② 基部だけでなく上行大動脈全体を安定化する　③ **しなやかなメッシュでautograftを隔離しないため滲出を許容する**

**成績（Redondo, London 50例, 2015–）**：平均29.8歳（最年少9歳、**14%が18歳以下**）、**38%が既往開胸**（11例は既往AVR）、72%が二尖弁、平均上行径3.83cm。CPB 200.7分／遮断151.1分、在院中央値6日、平均FU 16.9ヶ月。**死亡ゼロ**。2例が後にAVR（1例はリウマチ性、1例はautograft弁尖の医原性損傷）。**上行大動脈径は術直後から安定**。
