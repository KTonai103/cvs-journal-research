# 第10章　周術期管理・術中評価

## 10-1. 麻酔・体外循環の設計（Scorsese, JCDD 2025 — Ross専用の麻酔総説）

Ross手術の麻酔・体外循環を正面から扱った唯一の総説である。外科側にとっても、**送血部位の選択が術野の広さを直接決める**点で読む価値がある。

- **送血は腕頭動脈起始より遠位の弓部にSeldinger法で** → **遮断を腕頭動脈直近位に置けるため、PA分岐部より遠位で遮断でき、autograft採取と遠位肺動脈吻合が容易になる**
  - **TEEで術者のガイドワイヤーが近位下行大動脈の内腔にあることを確認する必要がある**（外科・麻酔の連携ポイント）
- 脱血は**両大静脈（単段カニューレ2本）**。PFOや心内同時手技があれば右房単独も
- **LVベントは右上肺静脈から僧帽弁を越えてLVへ。TEEで先端が僧帽弁・大動脈弁に当たっていないことを確認する**
- **心筋保護**：遮断時間が長いので順行性＋逆行性の併用。**逆行性を使う場合は冠静脈洞カテーテル位置をTEEでガイドして損傷を防ぐ**。del Nidoが多いが術者依存
- **血液温存**：acute normovolemic hemodilution と retrograde autologous priming（Stelzerもルーチン化）

## 10-2. 術前画像で見るべきもの（Ross特異的）

| モダリティ | 見るもの |
|---|---|
| **CTCA** | 冠動脈の走行、**短い左主幹**、右冠動脈起始異常 → autograft採取・再建を難しくする |
| **cMRI** | 弁の流体力学、心室機能、灌流、冠動脈奇形 |
| **CTA** | 大動脈基部と上行大動脈。**38–40mm超で同時手術を検討** |
| **肺動脈弁複合体の集中評価** | 弁尖形態・弁輪径・組織の質・**漏斗部筋（厚さ・強度・周囲構造との関係）**。四尖/二尖はautograft使用を妨げうる |
| **位置関係** | **肺動脈基部と左主幹・左心耳の位置関係**を精査して採取時損傷を避ける |

ただし第7章で見たように、**二尖・四尖肺動脈弁については術前画像の診断率は実質ゼロだった**（Filippa 11/11例が術中診断）。**画像で「除外できた」と考えてはいけない。**

## 10-3. 術中TEE

**術前（CPB前）**
- 大動脈弁輪・Valsalva洞・STJ・上行大動脈の計測
- 弁形態と交連配置
- **肺動脈弁機能と弁輪径**

**判定基準**
- **Namの基準**：**中心性の軽微な逆流は許容する。偏在性ジェットは弁尖prolapseや交連機能不全を示唆し、体循環圧では有意になりうる**
- **Skillingtonの方針**：三尖で弁尖サイズが均等、trivial〜mildの逆流までが許容。**二尖・四尖・cuspal asymmetryならRossを行わない**
- Bostonの加圧試験（第4章 4-3②）も同じ基準を使う — **中心性のごく軽度逆流は正常、交連部ジェットは治す**

**離脱後**
- **mildを超える残存ARは技術的問題を示唆し、再遮断の対象**である
- **Florida sleeve法では、TEEガイド下で最後のsubannular縫合を結紮してannuloplastyのきつさを決める**（Spindel）

## 10-4. 血圧管理 — 施設間で目標が違う

| 施設 | 目標収縮期血圧 | 期間 | 第一選択薬 |
|---|---|---|---|
| Mount Sinai（El-Hamamsy） | <110 mmHg | 6–12ヶ月 | β遮断薬（dP/dt低下） |
| Mount Sinai（Stelzer） | <110 mmHg | **特に最初の24–48時間を厳格に** | — |
| Melbourne | <120 mmHg | β遮断薬3ヶ月 | β遮断薬 |
| **Boston（円周補強）** | 入院中<110、**退院後<120** | — | amlodipine / labetalol / lisinopril / metoprolol / valsartan |
| Lübeck | 「生涯の血圧管理」 | 生涯 | — |
| EACTS Consensus | <110–115 mmHg | 1年 | β遮断薬 |

> [!question] 「補強の程度に応じて血圧管理の厳格さを変えてよいのか」
> Bostonは**円周補強をしているので在宅では<120で十分**と明示的に主張している。他施設は追随していない。
> これは論理的には筋が通る（補強が拡大を防いでいるなら圧の要求は下がる）が、**裏づけるデータはない**。第11章 対立点#8。

## 10-5. 抗炎症薬・抗血小板薬 — 根拠が最も薄い領域

| 施設 | レジメン |
|---|---|
| Melbourne / Mount Sinai / Montreal | NSAID 6ヶ月 |
| EACTS Consensus | イブプロフェン 5 mg/kg×3回/日を3–6ヶ月 |
| **Lübeck** | **クロピドグレル 75 mg/日×3ヶ月 ＋ イブプロフェン 400 mg/日×5週間** |
| Vienna（Ross-PEARS） | 低分子ヘパリン 6,000 IU を3週間 |

**期間も薬剤も施設ごとにばらばらで、比較試験は存在しない。** NSAIDの根拠は「autograftの炎症性リモデリングを抑える」という機序論に留まる。長期NSAIDの腎・消化管リスクとの釣り合いを論じた文献も見当たらない。**本レビューが扱った領域の中で、最もエビデンスが薄い。**

## 10-6. 生涯フォロー

| 施設・ガイドライン | フォロー間隔 |
|---|---|
| EACTS Consensus | 退院時 → 3–6ヶ月 → 以後年1回のエコー |
| Melbourne | 年1回の診察 ＋ 隔年エコー |
| London（PEARS） | 退院6週の外科診察 → 3ヶ月で循環器診察＋エコー → **1年でMRI** → 以後年1回エコー・2年ごとMRI |
| Bloom / Nam（MGH）のアルゴリズム | 図10-4 |

**間隔を決める2つの根拠**

- **Ramkaran**：**二尖弁・術前AR例では55mm未満でも破裂・解離が起こる**ため、監視間隔と介入閾値を個別化すべき
- **Chauvette**：**homograft機能不全の瞬間リスクは術後1年目が最大（3.5%/年）**で、以後<1%/年に低下する → **早期のフォロー間隔を密にする根拠**
