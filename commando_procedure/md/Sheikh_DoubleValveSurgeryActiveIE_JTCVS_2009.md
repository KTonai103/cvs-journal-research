> [!NOTE] Key Message
> Tirone David（Toronto General Hospital）の26年間DVS for active IE（n=90）。院内死亡15.6%、5年生存68%、10年生存49%。IVF再建（Commando）を含む複雑再建を要した例でも長期フォローを示した歴史的シリーズ。

## 要点

| 項目 | 値 |
|---|---|
| 施設 | Toronto General（David TE） |
| 期間 | 26年間 |
| n | 90 |
| 平均年齢 | 53±16歳、男性71% |
| PVE | 32例（36%） |
| S.aureus | 29% |
| 膿瘍あり | 51%（n=46） |
| 院内死亡 | **15.6%**（n=14） |
| 後期死亡 | 32.2%（n=29） |
| 5年生存 | 68±5% |
| 7年生存 | 59±6% |
| 10年生存 | 49±7% |
| 平均追跡 | 5.9±4.7年（0-18年、完全） |

**手術方針:** IVF浸潤例→ラジカル切除＋パッチ再建＋弁置換、限局例→修復
