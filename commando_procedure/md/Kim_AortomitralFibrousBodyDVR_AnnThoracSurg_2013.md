> [!NOTE] Key Message
> 韓国（Samsung Medical Center）のIVF再建DVR長期成績（n=30）。全例ウシ心膜使用。早期死亡6.7%と良好。5年生存74.6%（IE群）。Pettersson MMCTS 2014でも参照されている重要シリーズ。

## 要点

| 項目 | 値 |
|---|---|
| 施設 | Samsung Medical Center（Seoul） |
| 期間 | 1997-2010 |
| n | 30（男性20、女性10） |
| 平均年齢 | 52±15歳（9-77歳） |
| 適応 | IE 22例、小弁輪5例、脆弱弁輪3例 |
| 緊急手術 | 40%（n=12） |
| 再建素材 | ウシ心膜（全例） |
| 平均追跡 | 50.6±43.5ヶ月 |
| 早期死亡 | **6.7%**（n=2） |
| 後期死亡 | 16.7%（n=5） |
| IE群 5年生存 | **74.6%** |
| IE群 再手術回避率 | 84.8%（5年） |
| IE群 再発IE回避率 | 94.7%（5年） |

**早期合併症:** 出血6例、急性腎不全4例、完全房室ブロック3例
