> [!NOTE] Key Message
> **スペイン2施設・Commando変法の中期成績（n=78）**。根部置換あり（ROOT-Commando）vs なし（non-ROOT）で院内死亡・中期生存に差なし（1年76%、5年67%）。**再感染はあるが再発（relapse）はゼロ**。根部置換の必要性は感染波及範囲で決定され、両群の成績は同等。

## 1. 背景・術式的位置づけ

- 2施設（Puerta de Hierro Majadahonda大学病院 ＋ Hospital Clínic Barcelona）
- 研究期間：2014年4月〜2023年11月
- IVF浸潤IEに対するCommando変法の比較：根部置換の有無による成績差を検討

### 分類
| 変法 | 説明 |
|---|---|
| non-ROOT Commando | AVR + MVR + IVF再建（根部保存） |
| non-ROOT Hemi-Commando | AVR + MV修復 + IVF再建（根部保存） |
| ROOT-Commando | 根部置換 + MVR + IVF再建 |
| ROOT-Hemi-Commando | 根部置換 + MV修復 + IVF再建 |

## 3. ★手術手技の詳細

### 標準的Commando変法（Barcelona法）

**Debridement:**
- 正中胸骨切開
- 斜方大動脈切開 → 非冠尖 → IVF → AML方向 → 左房天蓋を開放
- すべての異物・感染疑い組織を切除
- **非希釈ポビドンヨード（原液）**でデブリードマン面を清拭

**IVF再建（核心）:**
- **グルタルアルデヒド固定ウシ心膜パッチを折りたたんで使用**
- パッチ縫合：僧帽弁縫合輪前方 + 両線維三角へ3-0ポリプロピレン連続縫合
- 各三角での連続縫合を独立した3-0 Prolene結節縫合でブロック（強化）
- 左房切開：パッチ外半分で閉鎖
- 大動脈弁：大動脈弁輪 + 心膜パッチに2-0 braided縫合糸で固定
- 大動脈切開右側：残余半パッチで閉鎖

**Mitral-sparing Commando（前尖温存可能例）:**
- 折りたたんだウシ心膜パッチを直接AMLに縫合
- 柔軟な帯状弁輪形成術バンドで後方弁輪形成
- SAMリスクを考慮してバンドサイズを選択

**根部置換の適応:**
- 感染が大動脈弁輪他部位に浸潤 → 通常縫合が不可能
- 大動脈根部疾患自体が置換適応（瘤・前回手術後の組織不良）

## 5. 臨床的意義 / 限界

**意義**
- 欧州2施設（スペイン）の現代的シリーズ（2014-2023）
- ROOT vs non-ROOT Commandoの院内・中期成績が同等であることを示した
- **relapse（同一感染再発）がゼロ** → 根治的デブリードマン + IVF再建の有効性を支持
- 原液ポビドンヨード使用やウシ心膜パッチ法など実践的手技を詳述

**限界**
- 多施設だが後ろ向き研究、選択バイアス排除困難（群間比較p値なし）
- ROOT群は非ROOT群より重篤（膿瘍・瘻孔が多い）なのに成績が同等→根部置換自体がリスクを増加させない可能性
- 追跡中央値4.69年（5年以降のデータ少ない）
