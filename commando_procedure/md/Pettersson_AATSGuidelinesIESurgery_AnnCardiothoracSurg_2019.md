## 2. 主要推奨事項

### ①チームアプローチ（Class I, LOE B/C）

- IE疑い患者は**心臓外科・心臓内科・感染症科・他科**を含む専門チームを持つ施設に早期紹介
- 手術する外科医は**弁修復・弁置換・再建手技に精通した経験豊富な弁専門外科医**であること
- "Endocarditis team"（ESC、ACC/AHAとも推奨）

### ②診断・術前計画

| 検査 | 推奨 |
|---|---|
| TTE + TEE | 必須（PVE疑いは特にTEE） |
| ECG gated CT | TEEと同等の診断能 → 膿瘍・仮性動脈瘤の範囲評価に優れる |
| MDCT | 膿瘍/仮性動脈瘤の解剖詳細評価 |
| SPECT-CT / FDG-PET-CT | 診断確認 + 末梢塞栓/転移性感染の検出 |

### ③手術適応

**標準的手術適応:**
1. 重篤な心不全 / 重度弁機能不全
2. 人工弁感染（PVE）
3. 弁尖を越えた浸潤（傍弁輪膿瘍・心腔内瘻孔）
4. 繰り返す全身塞栓（適切な抗生剤治療中）
5. 大きな可動性疣贅（>10mm、特にAML上）
6. 適切な抗生剤治療5〜7日以上で遷延する敗血症

**追加要素（意思決定の修飾因子）:**
- 神経学的合併症・他臓器合併症も総合的に判断
- **最終決定は治療チームのコンセンサスによる**

### ④手術タイミング

| 状況 | 推奨 |
|---|---|
| **手術適応が確立したら** | **遅延しない（as soon as possible）** |
| 重篤なAR/MRで心不全症状なし | 心不全発症を待たずに手術（NVE） |
| 浸潤性S.aureus PVE・早期PVE | 早期手術 |
| 非複雑性・非Staph・後期PVE | 抗菌薬単独で試みるが数ヶ月内に再発が多い |
| 大きな可動性疣贅（>10mm）＋塞栓 | 緊急/準緊急手術 |
| 脳卒中患者 | 神経科との緊密な連携、出血性転換のリスク評価 |

### ⑤術中管理の原則

**Debridement:**
- 感染組織・異物（縫合糸含む）の**根治的切除**
- 豊富な洗浄（局所抗菌薬・抗生剤は控えめ）

**弁修復vs弁置換:**
- **僧帽弁・三尖弁は修復を優先**
- 単純弁置換が必要な場合：弁選択は通常の弁疾患と同基準（機械弁 or 生体弁）

**浸潤性IEの再建方針:**
- 侵された弁・破壊の程度・利用可能な再建オプションによって個別化
- **大動脈弁側：Allograft（同種移植片）が依然として推奨**
  - 浸潤性IEでの弁輪破壊に対し
  - 再建が容易、止血良好、感染再発リスク低
- 僧帽弁側：有効なAllograft代替が存在しない → IVF再建（Commando）が必要

**抗菌薬:**
- 術時には感受性がある有効な抗菌薬を投与（感受性判明前は広域でカバー）
- 術後も全コース（静注）完遂

### ⑥Biofilm仮説と外科治療の意義

- IEはBiofilm関連感染 → 抗菌薬耐性・再発の原因
- 手術の意義：
  1. 感染組織・異物の除去
  2. Biofilmの機械的破壊 → 残存生菌を抗菌薬・免疫系に曝露
  3. 弁機能・心臓構造の修復

## 3. 関連する病態生理

| 病態 | 内容 |
|---|---|
| 起因菌 | Staphylococci + Streptococci + Enterococci ≒ 85% |
| PVE | NVEより浸潤性、抗生剤単独での治癒困難 |
| 大動脈弁IE | 浸潤性が多い（NVE・PVEとも）、手術成績はMV IEより良好 |
| 僧帽弁IE | 浸潤性では手術解剖が不利、Allograft代替なし → 成績が大動脈弁より不良 |

## 4. 臨床的意義 / 限界

**意義**
- 最も権威あるIE外科ガイドライン（AATS 2016）のエッセンスを Pettersson/Hussain 自身が解説
- Commando手術の適応（IVF浸潤性IE）に至る判断基準・手術原則を体系的に示す
- "手術適応確立→即手術"の原則 + チームアプローチが最重要メッセージ

**限界**
- 2016年ガイドラインの2019年版サマリー（最新IEエビデンスを完全には反映しない）
- Commando手術の具体的な手技詳細は別途参照が必要
