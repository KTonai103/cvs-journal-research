> [!NOTE] Key Message
> **Root-Commando with modified self-assembled aortic root conduit**のMMCTSビデオ症例報告（Hospital Clínic, University of Barcelona）。Sutureless AVR後のS. epidermidis早期PVEに対し、同種移植片やFreestyleの代わりに人工弁を人工血管内に組み込んだ自家組立コンジットを使用したRoot-Commandoを施行。緊急状況での移植片入手困難時の有用な代替技術。

## 要点

| 項目 | 値 |
|---|---|
| 施設 | Hospital Clínic, University of Barcelona, Barcelona, Spain |
| 論文種別 | MMCTS ビデオ症例報告 |
| 術者 | Eduard Quintana（対応著者）+ Ukrainian fellows（EACTS Fontan Fund） |
| 症例 | 68歳男性、4ヶ月前にMinimally invasive J-sternotomy + Perceval L (LivaNova) Sutureless AVR後 |
| 起因菌 | S. epidermidis（早期PVE） |
| 病変 | 大動脈根部膿瘍 + AMC瘻（LA方向） + 重症MR + 重症傍弁閉鎖不全 + AML大型疣贅 (2.5×1.3cm) + PFO |
| 術式 | Root-Commando（Sutureless弁摘出 + DVR + IVF再建 + 自家組立大動脈根部コンジット） |
| 新規性 | 23mm Sorin Bicarbon Slimline AV + 26mm Hemashield人工血管 = 自家組立コンジット |
| MV | 31mm Sorin Bicarbon Fitline機械弁（縫合糸はPML自由縁〜両線維三角） |
| IVF再建 | 二重層ウシ心膜パッチ（上層=LA天蓋閉鎖、下層=LVOT再建） |
| 結果 | 生存退院（神経学的後遺症なし）。院内合併症：Klebsiella肺炎 + 抗凝固移行中TIA |
| 大動脈遮断時間 | 255分 |
| CPB時間 | 296分 |

## 自家組立コンジットの利点

1. **入手容易性**: どの施設でも利用可能（緊急時に同種移植片が不要）
2. **柔軟性**: 3〜4mmのポリエステルスカートが不整・非円形の大動脈根部-LVOT接合部に適応
3. **弁葉干渉防止**: 通常の機械弁コンジット使用時に生じる僧帽弁-大動脈弁機械弁葉間干渉を防ぐ
4. **大弁輪確保**: 必要に応じてより大きい人工弁の使用が可能

## Root-Commandoの選択肢（著者整理）

| オプション | 特徴 |
|---|---|
| 1. Human allograft | 感染耐性最良・長期耐久性 |
| 2. Medtronic Freestyle (porcine root) | 入手可能施設限定 |
| 3. 市販生体弁コンジット | 硬直した縫合環が非円形環に不向き |
| 4. 市販機械弁コンジット | 両弁葉干渉リスク |
| 5. **自家組立コンジット** | **本論文の提案** |
