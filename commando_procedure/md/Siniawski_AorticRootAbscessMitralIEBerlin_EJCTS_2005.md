> [!NOTE] Key Message
> Deutsches Herzzentrum Berlin（Yankah/Hetzer）の大動脈根部膿瘍＋続発性僧帽弁IE（SMVD）の成績。327例のAIEのうち108例（33%）に根部膿瘍、そのうち53例（25.5%）がSMVD。ベルリンシリーズとしてのIVF浸潤IEの歴史的背景提供。

## 要点

| 項目 | 値 |
|---|---|
| 施設 | Deutsches Herzzentrum Berlin |
| 期間 | 1996-2003 |
| 全AIE | 327例 |
| 根部膿瘍例 | 108例（33%） |
| SMVD（続発性MV感染）| 53例（25.5%全体） |

| SMVD性別 | 男性37、女性16 |

**意義:** ベルリンの大規模IE外科シリーズ。続発性MV感染（大動脈根部膿瘍からの波及）の予後を分析。Commando適応の疫学的背景として重要。
