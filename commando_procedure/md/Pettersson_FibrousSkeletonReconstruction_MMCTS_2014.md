> [!NOTE] Key Message
> Commando手術（大動脈弁＋僧帽弁置換＋Intervalvular Fibrosa再建）の**クリーブランドクリニック定義手技論文**。IVF解剖・手術ステップ・落とし穴・成績を網羅したビデオ付きMMCTSチュートリアル。術後早期死亡率は高いが、マッチング後は通常DVRと同等。**Lateral trigoneの無張力再建が最重要**。

---

## 1. 背景・術式的位置づけ

- IVF（Intervalvular Fibrosa / Mitroaortic Intervalvular Fibrosa）の破壊はIEの重篤な病態を示す指標
- 主な原因：補綴弁（大動脈弁＋僧帽弁）への感染による酵素的破壊
- IVF再建を伴うDVRを「**Commando operation**」と命名（Cleveland Clinic）→ その難易度を示す隠語
- 名称の由来：Lytle（Cleveland Clinic）が1994年に手術図を作成、David et al. 1997年に最初の出版
- 非IE適応：高度石灰化（MAC）、多回弁手術後の組織不足、弁輪拡大目的でのIVF切開

## 3. ★手術手技の詳細（最重要セクション）

### 術前評価・適応判断
- 心臓エコー（経食道含む）、胸部CT（またはMRI）、心臓カテーテル
- **再開胸リスク評価**：大動脈・仮性動脈瘤・グラフトが胸骨に接触する場合は末梢カニュレーションを先行（腋窩動脈推奨）
- 標準は正中胸骨切開 + 二心房カニュレーション

### 体外循環設定・心臓アクセス
- 順行性 + 逆行性心筋保護（逆行性：冠状静脈洞へ8F自己膨張バルーン付きカニュラ直接挿入）
- 標準：横切開大動脈切開（右冠動脈起始部より1cm以上頭側）
- 必要に応じてSVC横断切離による追加露出（44% vs 2%）

### Radical Debridement 手技
1. 大動脈弁 + 根部デブリードマン（人工弁の場合はすべての縫合糸・感染組織を除去）
2. 非冠尖–左冠尖交連付近でIVFを切開し僧帽弁へのアクセス路を形成
3. 左房天蓋への切開延長（Figure 3A-B）
4. 僧帽弁人工弁の除去 + 弁輪デブリードマン（縫合糸を完全除去、弁輪を undermineしない）
5. 豊富な洗浄を各ステップ後に実施

### Aortomitral Continuity 再建手技（核心）

#### IVF の解剖的理解
- IVF = 僧帽弁前尖の基部から大動脈弁輪・大動脈弁をつなぐ線維性構造
- 右側：**中心線維体（右線維三角）**= 大きく固体的、伝導束が直下を走行
- 左側：**外側線維三角（左線維三角）**= 心室側壁筋・僧帽弁輪・大動脈弁輪を三角形に連結 → **最も重要**
- IVF = 僧帽弁輪周囲の1/3（前方）、後方筋性弁輪 = 2/3（三角間距離）

#### 僧帽弁のサイジング
- **IVF = 僧帽弁人工弁周径の1/3**（前方・大動脈側）
- **後方筋性弁輪 = 2/3**（三角間）
- サイジングはIVF切開前または仮再建後に実施（LVOT閉塞リスク評価）

#### 縫合アンカリング
- 僧帽弁を**先に植込み**（順序重要）
- 後方（三角間）：Pledget付き縫合糸を心室側から → 筋肉にしっかり固定（左回旋枝注意）
- 前方1/3：IVF再建パッチの縫合糸が人工弁縫合輪を貫通し大動脈弁側へ続く（独立した可動性を確保）
- 弁輪が軟らかく余裕のある縫合輪の人工弁を選択（ストレス軽減）

#### パッチ素材・サイジング
| オプション | 説明 |
|---|---|
| **大動脈同種移植片（第1選択）** | 大動脈弁側の再建に最適。同種移植片の僧帽弁をMVP縫合輪に直接縫合 |
| **自己心膜（第2選択）** | 追加素材として最優先 |
| **ウシ心膜** | 代替パッチ素材 |
| **合成素材** | 代替可 |

#### ダブルレイヤーパッチ法（非同種移植時の標準）
- **下葉**：左房天蓋の閉鎖に使用
- **上葉**：大動脈根部の再建に使用
- パッチは**両端に余裕を持たせたサイズ（generous）** で裁断
- 外側・内側の両線維三角にアンカリング

#### 大動脈弁の植込み
- 僧帽弁植込み・IVF再建**後**に大動脈弁を植込み
- 大動脈同種移植片使用時：同種移植片の僧帽弁をMVP縫合輪 + パッチに縫合

### Cavity管理・閉鎖
- **最重要ポイント：外側線維三角（Lateral Trigone）の無張力再建**
  - 僧帽弁人工弁が心室筋に固定されていること
  - 再建IVF＋外側三角が外側壁筋から大動脈弁輪まで無張力で固定されていること
  - 大動脈弁人工弁が再建IVFに縫合されていること
  - **体外循環離脱後のアクセス不可** → 離脱前に完璧な止血を確認
- 豊富な洗浄を繰り返し実施

## 6. 臨床的意義 / 限界

**意義**
- Cleveland Clinicの術式標準化論文：IVF解剖・手技ステップ・落とし穴を包括的に記述
- マッチング解析により、Commando術後の長期成績は通常DVRと同等であることを示した
- 大動脈同種移植片の優位性（感染環境での再建容易性・止血・感染再発低リスク）を明示
- 外側線維三角の無張力再建を最重要事項として特定

**限界**
- 単施設・レトロスペクティブ
- 期間が長く（37年間）、術式の変遷を完全には制御できない
- 症例数（n=51）は限定的
- MMCTSビデオチュートリアルであり、原著論文ではない
