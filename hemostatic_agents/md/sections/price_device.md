# 止血材（医療機器）の日本における価格・保険償還

**調査時点: 2026年7月12日**
**価格の根拠: 令和8年度（2026年4月1日適用）「特定保険医療材料及びその材料価格（材料価格基準）」**

---

## 0. 大前提：日本の医療機器は「償還される材料」と「されない材料」に二分される

厚労省「医療機器の保険適用等に関する取扱いについて」により、保険医療機器は次の区分に分けられる。

| 区分 | 意味 | 術者にとっての意味 |
|---|---|---|
| **A1（包括）** | いずれかの診療報酬項目に包括的に評価済み | **別途請求できない＝病院の持ち出し** |
| **A2（特定包括）** | 特定の診療報酬項目に包括的に評価済み | **別途請求できない＝病院の持ち出し** |
| **B（個別評価）** | **特定保険医療材料**として材料価格基準に個別収載され、償還価格がつく | **手術料とは別に請求できる** |
| C1/C2（新機能） | 新機能区分が必要なもの | 収載後はBと同じ扱い |
| F | 保険適用外 | 保険請求不可 |

出典: [医療機器の保険適用等に関する取扱いについて（厚労省）](https://www.mhlw.go.jp/content/12404000/000478353.pdf) / [PMDA 医療機器の保険適用について](https://www.pmda.go.jp/files/000273983.pdf)

**結論を先に述べる。心臓大血管外科で使う止血材の多くは、実は「特定保険医療材料」として償還がつく。**
ただし**ゼラチンスポンジ（ゼルフォーム／スポンゼル）は心臓外科では算定できず、完全に病院持ち出し**である（後述 §3）。ここが最大の実務上の落とし穴。

## 2. 算定要件（留意事項通知）— ここが術者の意思決定を決める

出典: [特定保険医療材料の材料価格算定に関する留意事項について（2026年度）](https://www.hokeni.org/docs/2026030500042/file_contents/2026_tokuzai_tuuti.pdf)

### 106 微線維性コラーゲン ← 心臓外科にとって最重要
通知原文（抜粋）:

> 微線維性コラーゲンは、肝、膵、脾、脳、脊髄の実質性出血及び硬膜出血並びに脊椎・脊髄手術における硬膜外静脈叢・硬膜近傍骨部、**大動脈切開縫合吻合部（人工血管を含む。）、心臓切開縫合閉鎖部、心臓表面、ＡＣバイパス吻合部、胸骨断面、肺切離面、胸膜剥離面及び縦隔リンパ節郭清部**、（中略）からの出血で、**結紮、レーザーメス又は通常の処置による止血が無効又は実施できない場合**において、止血に使用した場合に算定する。
> （2）微線維性コラーゲンは、**粉末状のもの、シート状のもの又は綿状のものにかかわらず算定できる**。
> （3）**ゼラチン止血・接着剤**は、**解離性大動脈瘤の解離腔、大動脈切開縫合吻合部（人工血管を含む。）、ＡＣバイパス吻合部又は肺若しくは肝切離面**に対し、結紮、レーザーメス又は通常の処置による止血・閉鎖が無効又は実施できない場合において、止血・閉鎖のために使用した場合に算定できる。

→ **大動脈吻合部・心臓表面・CABG吻合部・胸骨断面は明示的に算定対象**。ただし「結紮や通常処置で止血が無効／実施不能」という条件が付く（＝予防的なルーチン散布は算定要件を満たさない建前）。

### 104 ゼラチンスポンジ止血材 ← 落とし穴
通知原文:

> ゼラチンスポンジ止血材は、**痔疾患術後等における直腸肛門部の止血のために用いた場合に算定できる**。

→ **心臓外科でのゼルフォーム／スポンゼル使用は算定できない＝病院の完全持ち出し。**

### 166 外科用接着用材料
> 外科用接着用材料は、**1回の手術につき 32.4g を限度**として算定する。

→ BioGlue 10mL（10.8g）なら 3本分までが上限。それを超えた分は病院負担。

### 099 組織代用人工繊維布
> （1）**生体由来材料は、開心根治術又は大腿動脈、大腿静脈若しくは頸動脈の修復等に用いた場合に算定できる。**
> （2）心血管系用・心血管修復パッチ先天性心疾患用は、関連学会が定める適正使用指針に従って使用した場合に限り算定できる。なお、**心内欠損孔の閉鎖に要した本材料に係る費用は算定できない。**

→ ウシ心膜パッチ（生体由来）は「開心根治術／大腿動脈・大腿静脈・頸動脈修復」に限定。**下肢動脈パッチ形成（大腿以外）や末梢バイパスでの使用は算定要件外**の可能性があり査定リスクがある。

### 151 デンプン由来吸収性局所止血材
留意事項通知に**臓器・部位の限定なし**（2026年度通知を全文検索して該当記載なし）。→ 心臓外科での使用も算定可。

## 4. 未確認・注意事項（正直な限界の明示）

### ハイドロフィットの償還区分は特定できなかった
- 「保険償還価格 26,600円」という記載は複数の二次情報（医療ニュース）に見られるが、**筆者が令和8年度 材料価格基準の全区分（001〜217）を検索した範囲では、ハイドロフィットに対応する機能区分名（例:「中心循環系非吸収性局所止血材」）は存在しなかった**。
- 区分 166(2)「外科用接着用材料・特殊型」（28,800円/g）が該当する可能性はあるが、**これは推測であり一次情報での確認が取れていない**。院内の医事課／メーカーに確認されたい。
- 製品自体の存在・用途（胸部大動脈／弓部分枝の人工血管置換術の吻合部止血、ウレタン系、ヘパリン存在下でも止血可能）は日本心臓血管外科学会雑誌の症例報告でも確認できる（[ハイドロフィット使用後の遠隔期摘出例, J-STAGE](https://www.jstage.jst.go.jp/article/jjcvs/47/2/47_62/_article/-char/ja/)）。

### ネオベールの心臓大血管領域での算定
- 区分名が「**臓器欠損補強用**」であるため、大動脈外膜の補強・被覆といった用途で算定できるかは**査定リスクがある**。国循の調達リスト（2017年）では保険請求「可」・区分コード736700000（臓器欠損補強用）として運用されていた。院内ルールの確認を推奨する。

### フロシール／サージフローの mL→g 換算
- 償還単位は「1g当たり」だが製品は mL 表示。国立循環器病研究センターの調達リスト（2017年）ではフロシール 5mL が償還価 64,000円（当時の微線維性コラーゲン単価 ≈12,800円/g × 5g）として計上されており、**5mL＝5g として算定されていた**と読める。サージフローも「8mL(8g)」と規格表示されている。ただし**現時点の各院での算定量は医事課に確認すべき**。

### 経過措置：サージセルは「薬」から「材」へ完全移行済み
- 従来の**医薬品**「サージセル・アブソーバブル・ヘモスタット」は薬価削除・販売中止となり、**2024年3月31日で経過措置終了**。現在は**医療機器**「サージセル・アブソーバブル・ヘモスタットMD」（特定保険医療材料 区分151）のみ。
- 有効成分「酸化セルロース」が日本薬局方から削除され、止血機序が薬理作用でなく物理的作用と整理されたことによる（[医療機器の保険適用について（令和4年12月収載予定）, 厚労省](https://www.mhlw.go.jp/content/12404000/001010490.pdf)）。
- **実務上のインパクト**: 織布型が 8〜30.6円/cm²（旧薬価）→ 48円/cm²（特材）へ引き上げられた（最大約6倍）。

### 本セクションの対象外
- **フィブリン糊（ボルヒール、ベリプラスト、タココンブ）は「医薬品（薬価基準）」**であり、材料価格基準ではない。別セクション（薬価担当）を参照。

## 5. 術者向けサマリ：1症例あたりのコスト感と償還

| シナリオ | 使う材料 | おおよその償還額（病院収入） | 備考 |
|---|---|---|---|
| 弓部置換・吻合部のシール | ハイドロフィット 1本 | 約26,600円（**要確認**） | 区分未確認 |
| 弓部置換・吻合部の接着補強 | BioGlue 10mL | 約120,960円 | 32.4g/手術が上限 |
| 大動脈解離のフェルト補強 | テフロンフェルト（数十cm²）＋プレジェット20個 | 数千〜3万円台 | 133円/cm² ＋ 162円/個 |
| びまん性出血（心表面・胸骨断面） | フロシール 5mL | 約64,500円 | 「通常処置で止血無効」が算定要件 |
| びまん性出血（乾性パウダー） | アリスタAH 3g | 約37,800円 | デンプン由来（非生物） |
| 吻合部の面出血 | サージセル ニューニット 40cm² | 約1,920円 | 安価 |
| 心膜閉鎖／癒着防止 | ゴアテックスePTFE心膜シート | 394円/cm² | 099(1)② |
| **「とりあえずゼルフォーム」** | ゼラチンスポンジ | **0円（算定不可）** | **心臓外科では全額病院負担** |

### 実務的な含意
1. **ゼラチンスポンジだけは償還がつかない。** 安価だが病院持ち出し。逆に言えば「高価な止血材を使うと病院が損をする」という直感は、心臓外科領域では**多くの場合誤り**である（大半は特定保険医療材料として償還される）。
2. ただしいずれの区分も「**結紮や通常の処置による止血が無効または実施できない場合**」という算定要件が付されている（106）。ルーチンの予防的散布は算定要件を満たさない建前であり、記録上の裏付けが必要。
3. BioGlue の 32.4g/手術上限は、広範な大動脈解離症例では実際に到達し得る。
4. **償還価格 ≠ 病院の購入価格**。上表は償還価格（病院収入）。購入価格（病院支出）は入札・値引きで下がり、その差額が病院の利益となる。国循の2017年調達リストでは、例えば BioGlue 10mL の定価155,000円に対し落札単価132,000円、償還価145,800円であった（[国立循環器病研究センター 診療材料 入札リスト（2017）](https://www.ncvc.go.jp/procurement/tender/file/20170727_00list_sinryomaterial.pdf)）。
