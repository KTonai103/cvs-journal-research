# 心臓外科における止血剤・シーラントの実践的エビデンスレビュー

> 対象読者: 日本の心臓外科医。
> エビデンスの根拠は PubMed abstract コーパス（`hemostatic_agents/corpus/slices/*.txt`）、各製品の日本語電子添文（PMDA）、厚生労働省の薬価基準・材料価格基準告示、学会ガイドライン原文。
> **フルテキスト未確認で abstract のみに依拠した箇所、メーカー資料・専門家意見にとどまる箇所、そして「検索範囲内で見つからなかった」箇所は、すべて本文中に明示した。**

## 0. エグゼクティブサマリ

1. **止血剤・シーラントは、心臓外科のハードエンドポイント（死亡・再開胸・輸血）を改善しない。** 心臓外科で唯一十分な検出力をもつ大規模RCT（FIBER試験、待機的単独CABG n=1,445）は、フィブリンシーラントが一次・二次エンドポイントのすべてで無効であり、1回の輸血回避あたり€72,000かかると結論した [4]。心臓・血管外科に限定した唯一のメタ解析（21研究・7,622例）も、出血量−120.7 mL・止血時間−2.5分という「統計学的に有意だが臨床的には小さい」効果のみを示し、**輸血・再手術・30日死亡はいずれも有意差なし**とした [5]。
2. **EACTSは局所シーラントのルーチン使用を Class III（推奨しない）としている**（2017年版、2024年版も同じ記載を維持）[2,3]。STS/SCA/AmSECT/SABM 2021 PBMガイドラインでは、局所シーラント／止血マトリックスに対する推奨は**削除された**（残った推奨は局所抗線溶薬のみ）[1]。**「とりあえず予防的に撒く／貼る」はガイドラインに反する。**
3. **止血剤に手を伸ばす前にやるべきことの方が、はるかにエビデンスが強い。** 粘弾性試験（TEG/ROTEM）ガイド下の目標指向型輸血アルゴリズムは STS 2021 で **Class I, Level B-R** [1]、Cochrane 2026 update（35 RCT、大半が待機的心臓外科）で死亡 RR 0.76、外科的再介入 RR 0.63 [9]。術中止血チェックリスト（無料の介入）は4研究19,946例で**再開胸率を有意に減らしている** [10]。
4. **「何をしている道具か」を分けて考える。** 受動的止血材（ORC・コラーゲン・ゼラチン・デンプン）は患者自身の血小板と凝固因子に依存し、**ヘパリン化中・拍動性動脈出血ではほぼ無力**である（PROTECT試験でゼラチン＋トロンビンですら高圧大動脈縫合線の即時止血は16.0%）[28]。能動的止血材（フィブリン糊・TachoSil・FloSeal/Surgiflo）はトロンビンを持ち込むため凝固能への依存が低い。**接着剤（BioGlue・GRF・Hydrofit・シアノアクリレート）は止血剤ではなく、凝固カスケードに一切作用しない機械的封止材である。**
5. **接着剤の代償は遅発性に、年単位で現れる。** GRF糊は短期死亡率を下げた（12.6% vs 31.9%）が、**その生存者の16.0%が術後平均30か月で仮性動脈瘤を発症した**（同一論文）[69]。BioGlueはGRFより仮性動脈瘤が明らかに少ない（CT追跡177例で0.6%）[74] が、無害ではない（針穴からの内腔漏出10%・大動脈組織で22% [66]、横隔神経麻痺83%・洞房結節壊死100%（ブタ）[67]、小児で血管成長阻害と33.9%の吻合部狭窄 [65]）。
6. **Hydrofit（マツダイト）について**: 「Hydrofit止血後の仮性動脈瘤が目立つ」という臨床印象を**支持する文献も反証する文献も存在しない**。PubMed収載はわずか21件、RCTゼロ、仮性動脈瘤をアウトカムに設定した研究はゼロである。**ただし日本の添付文書は仮性動脈瘤を〔重大な有害事象〕として明記し、治験55例中1例・使用成績調査576例中2例（因果関係が否定できない有害事象として）計上している** [124]。さらに添付文書自身が「硬化被膜は吸水し**2〜3倍に膨潤**する」「硬化時に**炭酸ガスを発生**する」「体重50 kgに対し**5 gを上限の目安**」と規定している [124]。**エビデンスの不在は安全性の証明ではない**（§4.1）。
7. **日本固有の制約を知っておく。** ①液状フィブリン糊は**ボルヒールとベリプラストPの2製品のみで、いずれも牛肺由来アプロチニンを含む**（アプロチニンフリーのEvicel/Vivostatは国内未承認）。②**ゼラチンスポンジは心臓外科から消えた**（スポンゼルは2026年3月31日で経過措置満了・保険請求不可、ゼルフォームは出荷停止、スポンゴスタンは肛門手術のみが承認用途）。③CoSeal等のPEG系シーラントは国内で使えず、唯一のPEG製品デュラシールも2025年10月で受注終了。④**サージセルの禁忌に「大動脈の出血部」があり、トロンビンとの併用は添付文書上「併用注意」（酸性でトロンビンが失活）** [124]。
8. **コストと償還**: 心臓外科で使う止血材の**多くは特定保険医療材料として償還される**（微線維性コラーゲン 12,900円/g、デンプン由来 12,600円/g、外科用接着用材料 11,200円/g・**1手術32.4 g上限**）。**唯一ゼラチンスポンジだけは「痔疾患術後等の直腸肛門部」限定であり、心臓外科では算定不可＝全額病院持ち出し**である [140]。したがって「高いものを使うと病院が損をする」という直感は多くの場合誤りであり、正しい論法は「**効かないものを漫然と使わない**」である。再開胸1件の増分コストは€6,290であり、止血剤の薬剤費はその2%未満にすぎない [11]。

## 1. 分類と作用機序 — まず「何をしている道具か」を分ける

### 1.1 3つのカテゴリ

| カテゴリ | 定義 | 代表製品（日本で使えるもの） |
|---|---|---|
| **受動的止血材（passive hemostat）** | 物理的な足場・タンポナーデを提供し、**患者自身の血小板・凝固因子に血栓を作らせる**。凝固因子を外から供給しない | サージセル（ORC）、アビテン／インテグラン（微線維性コラーゲン）、アリスタAH（デンプン）、テフロンフェルト／ネオベール（補強材） |
| **能動的止血材（active hemostat）** | **トロンビン（±フィブリノゲン）を外から持ち込み**、凝固カスケードの最終共通経路を局所で実行する | ボルヒール／ベリプラストP（フィブリン糊）、タコシール（フィブリン被覆パッチ）、フロシール／サージフロー（ゼラチン＋トロンビン）、トロンビン液モチダ |
| **シーラント／接着剤（sealant / adhesive）** | 凝固カスケードに**一切作用せず**、化学的・機械的に組織を接着・封止する。**患者の凝固能に完全非依存** | バイオグルー（BSA＋グルタルアルデヒド）、ハイドロフィット（ウレタン系）、アロンアルフアA（シアノアクリレート）。※フィブリン糊は能動的止血材とシーラントのハイブリッド |

### 1.2 凝固能への依存マトリクス

| 製品 | 凝固能への依存 | ヘパリン化中（ACT>400秒） | 拍動性動脈出血 | 一次エビデンス |
|---|---|---|---|---|
| ORC（サージセル） | 低〜中（低pHで赤血球・血小板を凝集） | 力不足 | **添付文書上「大動脈の出血部」は禁忌** | 添付文書 [124]、動物 [5] |
| 微線維性コラーゲン | **高**（血小板に完全依存） | 減弱 | **添付文書上 禁忌** | in vitro [35]、添付文書 |
| ゼラチンスポンジ | **高** | 減弱 | 不適 | 抗凝固ウサギ大動脈吻合で無処置と有意差なし [—] |
| デンプン（アリスタAH） | **完全依存** | **ほぼ無効**（動物で10分止血 22% vs ゼラチン 78%）[57] | 無効 | 動物実験（複数・一貫）[57] |
| ゼラチン＋トロンビン（フロシール／サージフロー） | 中（患者のフィブリノゲンと血小板は必要。主機序は物理的タンポナーデと添付文書が明記） | **作用する**（心臓外科RCTで有効）[12,13] | **添付文書上 禁忌**（タンポン/プラグとして作用しない） | RCT [12,13]、添付文書 |
| フィブリン糊 | **低**（フィブリノゲンもトロンビンも製剤側） | **作用する**（抗血小板薬内服下でも4分止血 64.7% vs 圧迫 28.2%）[111] | 洗い流される→不適 | RCT [111] |
| タコシール | **低** | 作用するが**止血時間が有意に延長**（ブタで+75%）[25] | 不適（縫合が先） | 動物 [25] |
| BioGlue / GRF / Hydrofit / シアノアクリレート | **非依存** | **作用する** | 「乾いた面」が必要（活動性出血面には接着しない） | 添付文書・機序 |
| PEG系（CoSeal・デュラシール、国内では心血管に使えない） | **非依存**（IFUに "works independently from the patient coagulation" と明記） | 作用する | 乾燥面が必須 | メーカー資料・RCT [84,85] |

### 1.3 二つの原則

**原則1: 「接着剤は止血剤ではない」。** BioGlue添付文書は「体内の血液凝固とは**別の機序**で修復部位の組織蛋白と結合し柔軟な機械的接着を形成する」と明記する。Hydrofitの添付文書は**「血管を本品で接合・吻合しないこと（本品は止血を目的としたものであって、接合・吻合するための性能を有しておらず、これら操作の代用となるものではない）」**を〔禁忌・禁止〕に置いている [124]。**接着剤は縫合の代わりにならず、縫合の粗さを埋める道具でもない。** 抗凝固下ウサギ大動脈吻合モデルでは、**縫合数を4→8→12本に増やすだけで出血量が 108 mL → 43.9 mL → 21.3 mL に減り、止血剤なしで安定した止血が得られた**（動物実験）[—]。

**原則2: 「乾いた面にしか効かないもの」と「湿った出血面で働くもの」を混同しない。** シーラント（BioGlue・PEG・CA・Hydrofit）は活動性出血面では流されるため、**一度クランプ／遮断して乾かしてから塗る**ことが前提である。逆にフロシール／サージフローは湿潤環境で機能するが、「血の海」にそのまま流し込んでも無意味である（添付文書：液体を吸引除去したうえで使用）。

### 1.4 選択の考え方（出血の性状 × 凝固能 × 部位）

```
【出血は拍動性・噴出性か？】
  Yes → 縫合・フェルト補強・パッチが唯一の答え。
        止血材はどれも無効（ORC・コラーゲン・フロシールは添付文書上いずれも禁忌）。
        乾かせるなら接着剤（BioGlue/Hydrofit）で吻合部を「補強」する余地はあるが、
        それは止血ではなく機械的封止である。
  No（oozing / 面出血 / 針穴）↓

【凝固能は是正されているか？（ヘパリン中和・体温 >36℃・pH・フィブリノゲン・血小板）】
  No → まず是正する。局所止血剤で全身性凝固障害は代償できない。
        STS 2021: "the source of bleeding and the patient's coagulation profile
        are important factors that may preclude the actions of ANY AND ALL
        topical hemostatic agents" [1]
  Yes（＝局所性の oozing が残っている）↓

【部位はどこか】
  ・胸骨断面・心表面・剥離面の面出血    → ORC / 微線維性コラーゲン（安価・即使用）
      ※セルセーバー使用症例ではアビテン／インテグランは添付文書上「禁忌」
  ・不整形・深部・到達困難な低圧系oozing → フロシール / サージフロー
      ※拍動性・遮断中の血管・セルセーバー併用は禁忌
  ・人工血管の針穴・吻合線               → フィブリン糊（rubして2分待つ）±フェルト/PGA
  ・脆弱な解離大動脈の断端・偽腔          → フェルト＋糊（＝機械的補強）。BioGlue/Hydrofit
  ・広い面のシール・sutureless repair     → タコシール（3〜5分圧迫）
```

## 2. 各論

### 2.1 フィブリン糊（液状フィブリンシーラント）

**日本で使えるもの**: ボルヒール組織接着用（KMバイオロジクス）、ベリプラストPコンビセット組織接着用（CSLベーリング）。いずれも**医薬品・処方箋医薬品・特定生物由来製品**（薬価収載、20年間の使用記録保存義務）。Tisseel / Evicel / Artiss / Vivostat / VISTASEAL は**検索範囲内で国内承認を確認できなかった**。

**原理**: フィブリノゲン＋第XIII因子（A液）にトロンビン＋Ca²⁺（B液）を作用させ、凝固カスケードの最終共通経路のみを体外から丸ごと持ち込む。**患者の血小板・上流凝固因子を必要としない**。

**メリット**
- ヘパリン化中・抗血小板薬内服下でも作用する。ePTFE吻合部針穴出血の第III相RCT（n=140）で4分止血率 62.9% vs 用手圧迫 31.4%（p<0.0001）、抗血小板薬内服例でも 64.7% vs 28.2% [111]。
- 生体分解性で異物が残らず、アルデヒド系のような組織毒性・硬化がない。

**デメリット**
- **アナフィラキシー**: 日本の2製品はいずれも**牛肺由来アプロチニン**を含む。胸腔鏡下肺部分切除でボルヒール塗布数分後にBP 31/22 mmHgまで低下した日本人症例（**症例報告**、山口医学 69(3):141-144, 2020）があり、**糊の除去と2,500 mLの洗浄が奏効**した。胸部外科RCT（n=185）ではフィブリンシーラント群の**37.4%（34/91）に抗ウシアプロチニン抗体が産生**された（有害事象とは無関連）[113]。過去にフィブリン糊を使用された患者へのアプロチニン全身投与でアナフィラキシーを起こした症例報告もある。
- **スプレー使用時の空気/ガス塞栓（規制当局レベルの警告）**: NIHR HTA系統的レビューは「規制当局の5件の報告でフィブリンスプレーに伴う**空気塞栓による死亡**が記載されている」と明記 [6]。MHRAは世界で6件の生命を脅かす／致死的空気塞栓（Evicel 5件、Tisseel 1件）を報告し、いずれも**推奨より高圧・近接**での使用に関連するとした。**開圧: 距離≥10 cm、圧≤2.0 bar（開放手術）。噴霧ガスは空気ではなくCO₂。噴霧中はEtCO₂・SpO₂・血圧・心拍を監視する。**
- **機械的強度は弱い**: in vitroでBeriplastの接着強度はHydrofit・BioGlueより有意に弱く、独立したフィルムを形成できなかった [117]。**解離大動脈の吻合部補強を糊だけに頼らない。**
- **ORCとの併用は不可**（ORCの低pHでトロンビンが失活。サージセル添付文書に「併用注意：止血効果が低下」と明記）[124]。

**使いどころ / 使ってはいけない場面**
- 使いどころ: 人工血管の針穴出血、面出血、フェルト／PGAシートの担体。**ブタ大動脈縫合孔モデルで破断圧は rub-and-spray 109±16 mmHg・rub-and-rub 113±7 mmHg に対し、滴下 22±8 mmHg、噴霧単独 64±10 mmHg** [110]。**「擦り込む（rub）」ことと「2分以上待つ」ことが決定的**（30秒では有意に弱い）。末梢血管のネットワークメタ解析でも、**硬化1分のTISSEEL 1Cは用手圧迫と有意差がなかった** [112]。
- 使ってはいけない場面: **血管内・心腔内**（血栓形成・塞栓）、活動性の噴出性動脈出血（洗い流される）、感染創の被覆（膿の封入）、ORCの上への重層。

### 2.2 フィブリン被覆パッチ（タコシール）

**日本で使えるもの**: タコシール組織接着用シート（CSLベーリング、**医薬品**・特定生物由来製品）。TachoComb は販売終了（ウシトロンビン・ウシアプロチニン排除のため）。Hemopatch・Veriset は国内での承認・販売を確認できなかった。

**原理**: ウマ由来コラーゲンスポンジの黄色面にヒトフィブリノゲン＋ヒトトロンビンを固着。血液・体液で溶解し、その場で凝固カスケードの最終段階を再現する（active + sealant のハイブリッド）。

**メリット**: **調製不要・即使用可**（急性A型解離、LV free wall rupture で強い）。sutureless repair の主力。小児先天性心疾患の再手術で第一選択使用すると術中赤血球輸血量が有意に低い（後ろ向き、OR 0.1、p=0.0003）[—]。

**デメリット**
- **心臓外科におけるTachoSil単独のRCTは、検索範囲内で1本も見つからなかった。** 心血管領域のRCTは TachoComb H の PTFE suture-hole 出血（n=24, 2004年）[21] と、日本未導入デバイスである Hemopatch（上行大動脈、n=170）[20]・Veriset（vs TachoSil, n=90）[19] のみ。日本でタコシールを心臓外科に使う根拠は、**添付文書の効能＋肝/肺RCTからの外挿＋後ろ向き研究**に留まる。
- **心臓外科におけるTachoSil誘発炎症・癒着・遺残のヒトデータは「存在しない」と、当該領域のレビュー自身が明言している** [23]。再開胸を見据えた心膜面への大量貼付の是非を判断する材料がない。
- アナフィラキシー（**症例報告**）: 右中葉切除で2回目の貼付約10分後に収縮期血圧40 mmHg台へ急落、**全TachoSilを除去し生食洗浄したところ約10分で改善**、後日DLST陽性（日本呼吸器外科学会雑誌 2021;35(2):172-175）。禁忌に「ウマ血液由来製剤過敏症」。
- **抗血小板薬継続下の動脈性出血では威力が落ちる**: ブタ大動脈切開モデル（ヘパリン＋DAPT）で、フィブリノゲン-トロンビン被覆コラーゲンパッド（＝TachoSil相当）の**即時止血成功率は18%**、PEG被覆パッド（Hemopatch）は94%だった（**動物実験**）[26]。
- **blow-out type のLVFWRには不十分**: sutureless repair 35例で院内死亡17%、**re-rupture 17%**（うち67%が24時間以内）、**blow-out type 2例は両方ともre-rupture**（後ろ向き）[22]。

**使いどころ**: oozing type の心破裂、縫合線補強、広い面のシール。**貼付面を乾かし（濡らしすぎない）、黄色面を創面へ、3〜5分圧迫。**
**使ってはいけない場面**: 血管内腔・弁尖・冠動脈内腔側（**血管内混入で生命を脅かす血栓塞栓**）、活動性感染巣（重大な副作用に「膿瘍」）、拍動性動脈出血の一次対応。

### 2.3 フロアブル・ゼラチン-トロンビンマトリックス（フロシール／サージフロー）

**日本で使えるもの**: フロシール（バクスター、**ウシ**真皮由来ゼラチン＋ヒトトロンビン）、サージフロー（J&J、**ブタ**由来ゼラチン＋ヒトトロンビン2,000 IU）。いずれも**医療機器・高度管理医療機器・特定生物由来製品**（20年記録保存義務）。

**原理**: 添付文書が「**本品による止血の主たる原理はゼラチンの物理的特性による**」と明記。膨潤（**約20%、10分以内に最大**）による物理的タンポナーデ＋血小板の足場＋トロンビンによるフィブリン形成。

**メリット**
- **不整形・深部・到達困難な出血面に流し込める**。低圧系（右房・SVC・無名静脈）は動物実験で1〜2分で止血 [44]。
- 心臓外科RCTのエビデンスがクラス中で最も厚い。**Fusion Matrix Study（n=93、通常止血が失敗した心臓手術の出血点）: 10分止血 FloSeal 94% vs Gelfoam+トロンビン 60%（p=0.001）、3分 72% vs 23%（p=0.0001）** [12]。**Nasso（n=415、待機的心臓・胸部大動脈手術）: 止血成功率・止血時間・術後出血量・輸血率のすべてでFloSealが有意に良好（いずれもp<0.001）。ただし再開胸率は全体では有意差なし**（「明らかな術中出血」サブグループのみ p=0.04）[13]。全身低体温でも優位性は失われなかった。

**デメリット・注意（心臓外科に固有）**
- **セルセーバー併用禁止**（添付文書）: 「コラーゲン系止血剤の断片が血液回収システムの**40 µm輸血フィルターを通過する**との報告がある」。**本剤を使った術野の吸引ラインの扱いを術者・臨床工学技士で申し合わせる必要がある。**
- **血管がクランプ／バイパスされ血流が少ない状態での使用は禁忌**（血管内凝固のおそれ）。**大動脈遮断中の吻合部への適用は添付文書に正面から抵触する。**
- **末梢静脈圧が陰圧となる体位・状況では使用しない**（フロシール【警告】の筆頭。「生命を脅かす血栓塞栓症を起こす可能性」）[124]。
- **拍動性動脈出血には禁忌**（タンポン／プラグとして作用しない）。
- **塞栓**: ブタ椎弓根注入モデルで**右室流出路に大量の塞栓シャワー**、肺小血管内にFloSealと一致する物質を組織学的に確認（**動物実験**）[40]。頭頸部手術で翼突筋静脈叢に10 mL適用後の**症候性肺塞栓5例**（**症例集積**）[41]。頭蓋内腫瘍932例の後ろ向きで**10 mL超の使用量で血栓塞栓イベント率が高い** [42]。
- **アナフィラキシー（ゼラチン）**: 術中アナフィラキシー21例のレビューで、**57%が18歳未満、57%が脊椎手術、100%に客観的過敏証拠、33%は術前から既知のゼラチンアレルギー（ワクチン・赤肉・ゼリー等）**があった [37]。**ウシ・ブタ双方のゼラチン特異的IgEが陽性となる報告があり、「もう一方に替えれば安全」とは言えない** [38]。
- **遺残・肉芽腫・pseudomass**: 頭蓋内残存GTMはCTで**pseudoair（HU ≤ −100）**、MRIで空間占拠性pseudomassに見える [43]。心臓外科でも術後CTの心嚢内異常陰影の鑑別に必要な知識である。
- **感染**: 婦人科骨盤手術413例の多変量解析で、**gelatin-thrombin matrix使用のみが骨盤膿瘍の独立予測因子（OR 7.0, 95%CI 1.5–32.9）**（後ろ向き）[39]。

**フロシール vs サージフロー**: 2013年以降のPremier実臨床データ（PSM 5,768対）では**心血管手術の臨床アウトカムはほぼ同等**（出血イベント 6.9% vs 7.2%, P=0.576）[17]。2014年の「Surgifloが劣る」というPremier解析 [16] は**筆頭著者がBaxter（FloSeal）社員**であり、群サイズが極端に不均衡（4,480 vs 326）、かつ2012年の再製剤化前の製品を評価している。**製品選択の根拠にしてはならない**（§6.2）。

**使いどころ**: プロタミン後の低圧系びまん性oozing、不整形面、ポートサイト。
**使ってはいけない場面**: 拍動性動脈出血、遮断中の血管、セルセーバー回収域、閉鎖腔への過剰充填（20%膨潤）、感染巣。**止血後は余剰を必ず洗浄・吸引除去する**（添付文書【警告】）。

### 2.4 酸化再生セルロース（ORC／サージセル）

**日本で使えるもの**: サージセル・アブソーバブル・ヘモスタットMD（綿型／ガーゼ型／ニューニット型、承認番号 30400BZX00112000）、サージセル スノー、サージセル・パウダー。**2022年5月に医薬品から医療機器へ移行**し、2022年12月に特定保険医療材料化、医薬品版は2024年3月31日で薬価削除。

**原理**: **受動的止血材**。血液を吸収して膨潤し褐色ゼラチン状塊（pseudo-clot）となり、低pH（酸性）で赤血球・血小板を凝集させる。トロンビンもフィブリノゲンも含まず、酵素反応を触媒しない。

**メリット**: 調製不要・即使用・安価・常温保存・裁断可能・血液由来成分なし。**心臓外科で最も広く使われている第一選択のoozing対策**。

**デメリット（心臓外科医が知っておくべき3点）**
1. **添付文書の禁忌に「大動脈の出血部」が入っている**（十分な止血効果を得られないため）[124]。ORCは吻合部のjet bleedingを止める材料ではない。
2. **トロンビンとの併用は添付文書上「併用注意」**（本剤の低pHによりトロンビン活性が低下）[124]。**サージセルを敷いた上にフロシール／フィブリン糊、は禁じ手。**
3. **遺残物が膿瘍・腫瘍・感染に「見える」（最も実害の大きい合併症）**:
   - AVR後の発熱＋TEEでの大動脈弁周囲エコー源性腫瘤が**早期人工弁感染性心内膜炎に見えた**（症例報告）[47]
   - AVR＋上行/hemiarch置換でグラフトcontouringに使用したSurgicel Fibrillarが、**air bubblesを伴うperigraft abscessに見えた**（2週後CTで縮小・気泡消失、感染を否定）（症例報告）[48]
   - 新生児の先天性心疾患術後に**縦隔炎と誤診され早期再開胸**（症例報告）[49]
   - 僧帽弁形成後の縦隔packing（Nu-Knit）による**遅発性SVC閉塞**で再開胸・掻爬（症例報告）[50]
   - **肺癌手術200例の前向きコホート**で、4〜60か月後のCTで16例に縦隔リンパ節腫大、EBUS生検で**全例異物肉芽腫**。著者は「胸部外科で止血材として使うべきでない」と結論 [51]
   - **対策**: 余剰を除去し、**手術記録に使用部位を明記して放射線科医と共有する**（複数報告の共通結論）。

**「殺菌性」の実際**: in vitroの抗菌性は再現性があるが、**SSIをエンドポイントとした臨床試験は乏しく、周術期感染対策の代替にはならない**（批判的レビュー）。むしろ婦人科607例の後ろ向きで**術後骨盤膿瘍 ORC 10.4% vs フィブリンシーラント 0%**（p<0.05）[52]、肝切除RCT（n=45）で**Surgicel群の術後出血 33.3% vs 0%、肝周囲膿瘍・巨大血腫が発生し「推奨しない」** [53]。心臓外科では**縦隔炎アウトブレイク時の後ろ向きコホート（n=87）**で、CDAH（セルロース由来止血材）の使用頻度と感染リスクに有意な線形関係（3.3%→22.6%, P=0.024）が認められ、**製品使用中止後1年間で新規発生ゼロ**となった [54]。ただしこれはエコロジカル解析であり因果推論の強度は低い。

**RCTでの位置づけ**: **心臓外科でORC「使用 vs 非使用」を比較したRCTは存在しない。** 一方、**ORCを対照群に置いたRCTは複数あり、そのすべてでORCが劣勢である**（微線維性コラーゲンに対し24時間ドレーン 571±144 vs 373±143 mL, p=0.01 [27]；Vivostat自己フィブリンに対し止血時間 3.3分 vs 1.6分, p<0.0001 [55]；FloSealに対し全項目で劣位 [13]）。

**使いどころ**: 安価・即使用可能なファーストラインのoozing対策（胸骨裏面、心膜切開面、グラフト周囲）。
**使ってはいけない場面**: **大動脈の出血部（禁忌）**、トロンビン系との重層、汚染創への留置、血管の締め付けラッピング（狭窄報告）、パッキング目的の留置。

### 2.5 コラーゲン／ゼラチンスポンジ（受動性局所止血材）

**日本で使えるもの（2026年7月時点の重要な変化）**
- **BDアビテン／インテグラン（微線維性コラーゲン、ウシ真皮由来）**: 医療機器・特定保険医療材料（償還分類名「微線維性コラーゲン」）。**販売中。**
- **スポンゼル**: **2025年9月販売中止 → 薬価基準経過措置が2026年3月31日満了 → 2026年4月1日以降は保険請求不可** [146]。
- **ゼルフォーム**: 出荷停止が長期化し**実質入手困難**（2026年の本邦報告は "global discontinuation of Gelfoam" と記載）。
- **スポンゴスタン**: 承認された使用目的が**「肛門手術後における直腸肛門部の止血」に限定**＝心臓外科での使用は適応外。
- → **検索範囲内では、心臓血管外科領域の止血を承認された使用目的とするゼラチンスポンジ単剤製品を、日本で特定できなかった。** Hydrofit＋スポンゼルの「French toast法」[130] など本邦発の手技は再設計が必要である。

**原理**: コラーゲンは**血小板を直接接着・活性化**（受動性材料の中で止血活性が最も高い: in vitroで collagen > gelatin > ORC）。ゼラチンは物理的タンポナーデが主体で、**トロンビン浸漬で初めてactive化**する（この非対称性が両者最大の使い分け。**アビテンは濡らすと止血効果が低下するためトロンビン溶液に浸すのは不可**）。

**心臓外科での実力（数字で見る限界）**
- **Colgel（微線維性コラーゲン）vs Surgicel、高出血リスク心臓手術のRCT（n=71）**: 24時間ドレーン 373±143 vs 571±144 mL（p=.01）。**本クラスの心臓外科における最も強いエビデンス**だが、単施設・非盲検 [27]。
- **PROTECT試験（RCT, n=158、AVR/上行/基部置換）**: 対照の **Gelfoam Plus（ゼラチン＋トロンビン）群の即時止血達成はわずか16.0%、大動脈縫合線の止血成功40.0%、bleeding time中央値10.0分** [28]。→ **トロンビンを足してすら、抗凝固下の高圧縫合線に対する受動性スポンジの実力はこの程度である。**
- 抗血栓薬下ではさらに見劣りする: Fibrocaps vs ゼラチンスポンジ単独の血管手術RCT（n=175）で、抗血小板薬単独・抗凝固薬単独・両者併用のいずれのサブグループでもFibrocaps優位 [31]。

**デメリット**
- **セルセーバー併用は添付文書上「禁忌」**（本品はフィルタを通過する）。犬腎灌流モデルでは20 µmフィルタを通過したMCH粒子により**5日後に腎実質の多発性血管周囲炎症反応**が生じた（動物実験）[34]。in vitroでは20 µmフィルタで97%以上除去できるというデータもある [36] が、**「アビテンを置いた領域は吸引しない」等の運用の安全性を検証した臨床研究は存在しない（＝推測）**。
- **拍動性動脈出血・血液貯留部位・感染部位は禁忌**（アビテン添付文書）。
- **骨癒合阻害**（動物実験）: 微線維性コラーゲン・ORCとも早期骨治癒を阻害する [141]。**胸骨断面に使う際に留意すべき所見。**
- 異物肉芽腫、膨張による神経圧迫、ウシコラーゲンによるアナフィラキシー（症例報告）。

**使いどころ**: 胸骨骨髄断面（ボーンワックス代替）、心筋・心膜・剥離面のびまん性oozing、ヘパリン中和後の閉胸前oozing。
**使ってはいけない場面**: セルセーバー使用症例（添付文書上の禁忌）、高圧の大動脈縫合線、拍動性出血、感染部位。

### 2.6 多糖類系（アリスタAH）

**日本で使えるもの**: バード アリスタAH のみ（メディコン、**医療機器**、承認番号 22600BZX00455000）。PerClot・EndoClot・HEMOBLAST・Starsil は国内承認を確認できなかった。

**原理**: 植物デンプン由来の微小多孔性球状粒子が血液の水分を吸収し、血小板・赤血球・凝固因子を粒子表面に濃縮する。**トロンビンもフィブリノゲンも含まない完全な受動的止血材で、患者の凝固能に完全依存する。**

**最大の弱点（心臓外科では決定的）**: **ヘパリン化中はほぼ効かない。** ヘパリン化動物モデルで一貫している — ブタ肝擦過でFloSealに対し止血成功オッズ比 0.035（5分）[57]；10分止血成功率 MPH 22% vs ゼラチン 78%、止血中央値 14.5分 vs 1.6分 [57]；ヘパリン化ラット総頸動脈切断で**MPH単独は圧迫のみと差なし** [57]。添付文書も「本品を血液凝固不全治療の第一選択としないこと」と明記。**使うならプロタミン投与後**。

**メリット**
- **非動物・非ヒト由来**（ウシトロンビン・ウシコラーゲン・ヒト血漿を含まない）。宗教的理由や生物由来製品を避けたい症例で唯一の選択肢になりうる。
- 調製時間ゼロ。心臓胸部外科240例の後ろ向きで、**プロタミン〜閉創時間 93.4±41分 vs 107.6±56分（p=0.02）、48時間胸腔ドレーン 1594±949 vs 2112±1437 mL（p<0.001）、48時間RBC 2.4±2.5 vs 4.0±5.1 U（p<0.001）**、30日死亡・合併症に差なし [56]。**ただし後ろ向き・非ランダム化であり適応交絡（出血が少ない症例に使った可能性）を排除できない。心臓外科での無処置対照RCTは存在しない。**
- 速やかに吸収され残存しない（ラットで12時間でほぼ完全分解）[58]。→ 画像上の「腫瘤様残存」による再手術の混乱が起きにくい。**ただしヒトでの吸収期間を直接測定した臨床研究はなく、日本の添付文書にも吸収期間の記載はない。**

**デメリット・注意**
- **糖尿病患者への使用が禁忌**（血糖値に影響を及ぼすおそれ。デンプン＝グルコースポリマー）— 他剤にないアリスタ固有の項目 [124]。
- **膨張による圧迫壊死**の【警告】。骨孔・胸骨骨髄面に散布したら**必ず余剰を洗い流す**。
- **術野回収血を返血する場合は 20–40 µmフィルタの介在が添付文書上の要求事項**。
- 血管内適用は禁忌（塞栓）。有害事象欄に「血管の塞栓」「膿瘍形成」「死亡」の記載あり（頻度・因果の記載なし）。
- 同クラスのPerClotは吸収されず異物反応を起こし、**CIED植込みRCT（n=51）が術後発熱 28% vs 0%（p=0.004）などの安全性懸念で早期中止**された [59]。Aristaとは別物と考えるべきだが、クラスの「安全神話」を無批判に受け入れないための材料になる。

**使いどころ**: プロタミン後の面状oozing（心膜切離面、胸壁、胸腺床、LVADポケット）。
**使ってはいけない場面**: CPB中（ヘパリン化中）、動脈性出血、needle-hole bleeding、糖尿病患者、血管内。

### 2.7 BioGlue と GRF糊（アルデヒド架橋型接着剤）

**日本で使えるもの**: **バイオグルー外科用接着剤**（Artivion製造／センチュリーメディカル販売、医療機器、承認番号 22200BZY00003000、特定保険医療材料 区分166(1) 標準型）。**GRF糊は、日本における現在の承認区分・入手可否を示す一次資料が見つからず、「未承認」とも「承認済」とも断定できない。**

**原理**: グルタルアルデヒドの2つのアルデヒド基が、ウシ血清アルブミンのリジン残基および**組織側の蛋白のアミノ基と共有結合**し、機械的架橋足場をつくる。添付文書に「**体内の血液凝固とは別の機序**で…柔軟な機械的接着を形成する」と明記。**凝固カスケードのどこにも作用しない。**

**メリット**
- 凝固能に非依存で、**脆弱組織を"硬化"させて縫える壁にする**。
- **多施設RCT（Coselli、n=151）で吻合部出血 18.8% vs 42.9%（p<0.001）** [61]。これが日本の承認根拠。**ただし主要評価項目は術中止血であり、遅発性の仮性動脈瘤・再解離を検出する検出力も追跡期間もない。**
- **「BioGlueが解離手術の死亡率を下げる」という主張を支持するRCTは無い**（添付文書記載の外国試験121例では死亡率 33.3% vs 27.9%、有意差なし。対応する査読論文のPMID/DOIは特定できず、メーカー資料レベル）。
- 末梢血管RCT（n=100）では止血時間 4.4分 vs 9.6分（p<0.001）だが、**院内出血（再介入含む）は 18% vs 14%（p=0.39）で差なし** — **臨床的に意味のあるアウトカムは改善していない** [62]。

**デメリット（機序から一貫している）**
- **遊離グルタルアルデヒドの組織毒性**: **重合を完了した**BioGlueの生食上清中に**グルタルアルデヒド100〜200 µg/mLが遊離**し、ヒト線維芽細胞・マウス筋芽細胞に細胞毒性を示し、ウサギの肺・肝で**中毒性壊死**を来した（in vitro＋動物）[63]。**「重合したら不活性になる」は誤りである。**
- **コンプライアンス・ミスマッチ**: BioGlueの弾性率 **3,122±1,640 kPa** に対しCoSeal 100 kPa、Tisseel 103 kPa。**Dacronグラフト・ヒト大動脈組織のいずれよりも「はるかに硬い」**（in vitro）[64]。
- **小児は禁忌**: 子ブタ無作為化実験（n=10）で、BioGlue補強群は**内腔面積 33.9%狭窄 vs 対照 3.7%（p=0.038）**、全例で外膜線維化。「小児患者の心血管吻合部には使用すべきでない」[65]。**これが添付文書の小児禁忌の直接の根拠。**
- **針穴からの内腔漏出＝塞栓源**: ベンチ実験（180吻合）で**全体10%、新鮮大動脈組織では22%**（人工血管6%、p=0.003）で内腔へ漏出。**糸のサイズを変えても、ePTFE糸にしても漏出は消えなかった** [66]。臨床では術後5日目の脳塞栓（血栓回収で確認）[79]、Bentall後のLAD塞栓（OCT/IVUSで結晶様腫瘤として可視化）などの**症例報告**がある。
- **横隔神経・洞房結節障害**: ブタ18頭で、BioGlue群の**5/6（83%）が30分で横隔膜麻痺**、大静脈–右房接合部塗布で**12頭全例に心筋に及ぶ凝固壊死**、2頭（17%）に**洞房結節の巣状変性と持続性徐脈**。**水溶性ゲルバリアが保護的**だった [67]。**これが添付文書【警告】の根拠であり、同時に実行可能な予防策でもある。**
- **冠動脈入口部の外部圧迫狭窄**: modified Bentall後のLMCA外因性狭窄（IVUSガイドPCIで治療）[76]、**病理でBioGlueと確認されたLMT狭窄をDCAで摘出**（著者は「**スポンジを内腔に詰めても糊の侵入は防げなかった**」と明記）[77]。GRFでは冠動脈入口部の硬い線維性圧迫に**ステントが無効**で外科的再建を要した [78]。
- **アナフィラキシー・BSE**: 胸腹部大動脈置換中の塗布直後のアナフィラキシーショック（症例報告）[80]。国内治験で**抗BSA IgG・IgE抗体の産生が確認**されており、**添付文書は反復使用を禁忌**とする。→ **BioGlue使用歴は必ずカルテと患者に残す。**
- **他臓器では毒性がより顕著**: 小児脳外科75例中**10例（13%）に創合併症**、全例でBioGlue周囲に膿を認め、著者は「今後の使用を推奨しない」と結論（後ろ向き）[81]。腋窩郭清のRCTでも強い異物反応で再手術に至り推奨されない。

**GRF糊が捨てられた歴史（Hydrofit評価のテンプレート）**
| 段階 | GRFでの実際 |
|---|---|
| ① 手術が容易になる体感 | 「脆い壁が縫えるようになった」（1977年 Bachet 導入） |
| ② 短期成績の改善を示す観察研究 | 院内死亡 31.9% → 12.6%（p<0.0001）[69] |
| ③ **長期成績を主要評価項目とした前向き研究の不在** | 20年間ついに実施されず |
| ④ 症例報告 → 後ろ向きコホートで遅発性合併症が出現（3〜5年遅れ） | **同じ論文が「生存194例中31例（16.0%）に術後1〜65か月（平均30か月）で仮性動脈瘤」と報告** [69]。他施設でも 7.0%（5〜27か月、病理で中膜平滑筋核の消失＝組織壊死）[68]、21%（24〜42か月）[70]、弁resuspension併用では**晩期AR再発 64% vs 対照 0%**、III度房室ブロック 15% [71] |
| ⑤ 機序が最初から予測していた | アルデヒド固定＋コンプライアンス・ミスマッチ [63,64] |
| ⑥ 「使い方が悪かった」説の否定 | **ホルマリン減量では中期再解離は防げなかった**（56% vs 38%、有意差なし）[72] |
| ⑦ 撤退宣言 | 2000年、Bingleyら「**我々はGRF糊の使用を、満足できない長期合併症のために中止した**」[73] |

**BioGlue と GRF を同列に扱ってはならない**: 分母のあるデータでは、**BioGlue使用233例のCT追跡177例（平均2.4年）で吻合部仮性動脈瘤は1例（0.6%）のみ** [74]、99例の比較でも群間差なし [75]。**GRFの7〜21%とは桁が違う。** ただし [74] のCT追跡期間中央値は0.6年（IQR 0.2–3.6年）と短く、GRFの仮性動脈瘤が出現する時期（平均30か月）に達していない可能性は否定できない。

**実務上の要点**
1. **必要最小限・薄く・均一に**（解離腔は幅約2 cm×厚約2 mm）。過剰塗布は接着に寄与せず毒性だけを足す。
2. **全周性に取り囲まない**（狭窄機序）[65]。
3. **真腔・冠動脈口・弁尖・心腔内・洞房結節・横隔神経を物理的にブロックしてから塗る**（ガーゼ／バルーン／ネラトン、必要なら冠動脈カテーテル）。**水溶性ゲルによるバリアは動物実験で保護的** [67]。
4. **プライミング（試し出し）を省略しない**（未反応BSAと遊離グルタルアルデヒドの直撃を防ぐ）。
5. **塗布後2分待ってから血流再開。塗った後は内腔を洗浄・確認する**（針穴漏出22%）[66]。
6. **遠隔期のCTフォローを組む**（仮性動脈瘤・再解離は術後1〜5年に出る）。
7. **小児禁忌、反復使用禁忌。**

### 2.8 Hydrofit（ハイドロフィット／マツダイト）

→ **安全性の詳細な検証は §4.1 に独立の章を設けた。** ここでは製品プロファイルのみ示す。

**日本で使えるもの**: 販売名**マツダイト**（三洋化成工業製造／テルモ販売）。一般的名称は**「中心循環系非吸収性局所止血材」**（承認番号 22300BZX00467000、高度管理医療機器、**特定生物由来製品に該当せず**）[124]。海外名 AQUABRID。

**原理（添付文書原文）**: 「反応性のイソシアネート基（–NCO）を両末端に有する**ポリエーテル系含フッ素ウレタンプレポリマー**…血液や生体組織表面の**水分と反応して炭酸ガスを放出しながら**逐次高分子化し、血管吻合部に密着したゲル状の柔軟な重合物となり…止血する」[124]。**1液型（混合不要）、硬化3〜5分。凝固カスケードには作用しない。**

**メリット**
- **生物由来原料を一切含まない**（血液媒介感染症リスクなし、特定生物由来製品の20年記録保存義務も生じない）。
- **人工血管への接着に強く、BioGlueより柔軟**: in vitroでコラーゲン–ポリエステル／コラーゲン–ePTFE間の接着強度はHydrofit > BioGlue > Beriplast（p<0.01）、破断までの伸長率・最大応力もHydrofit > BioGlue（**in vitroのみ**。著者自身が in vivo 検証の必要性を明記）[117]。
- 治験（添付文書【臨床成績】）: プロタミン直前の止血率 **79.1% vs 対照 38.5%（p<0.001）**、15分後 88.3% vs 60.7%（p<0.001）[124,125]。
- 急性大動脈解離の多施設後ろ向きPSM（94ペア）で術中輸血 34 vs 50単位（p=.03）、手術時間 343±92 vs 402±161分（p=.03）、**術後合併症発生率は同等** [119]。

**デメリット・添付文書上の制約（一次資料）**[124]
- **非吸収性の永久異物**（一般的名称そのもの）。イヌで**術後16か月以上残留**、ウサギで26週以降も単核球＋線維性被膜に囲まれた状態で観察。ヒトでは**4年8か月後の再手術時に薄膜エラストマーとして原型を保って摘出**された [121]。
- **硬化被膜は吸水し2〜3倍に膨潤する**（添付文書。海外メーカー資料は "doubles its regional volume"）→「吸水膨潤による圧迫が正常な機能を妨げる可能性」。
- **硬化時に炭酸ガスを発生するので、切開手術以外の術式における使用は避けること**（ガス圧による周辺組織の一時的圧迫）。
- **用量上限の目安: 体重50 kgの患者に対して5 g**（生物学的安全性試験に基づく）。**大血管径（約20 mm）の全周塗布で約1 g、小血管径（約5 mm）で約0.25 gが目安。**
- **禁忌**: 血管内使用／血管内を陰圧に処置する状況での使用（塞栓）、汚染・感染した血管吻合部（**殺菌作用をもたない**）、**血管の接合・吻合（本品は縫合の代用ではない）**、**脳血行再建術（脳血管に対する安全性が明確でないため）**。
- **警告**: 止血に必要な最少量に止める（**非吸収性の本品が過剰に残存すると炎症等の生体組織反応が高まる**）／**ヘパリン中和前の凝固能低下下では特段の必要性がない限り使用しない**／透過性の低い人工血管吻合部では慎重に検討／硬化被膜を無理に引っ張らない／付属シートを体内に残さない。
- **自己血回収装置使用時は硬化完了前の本品を吸引しない。**
- Surgicelとの併用（本邦で広く行われる）は止血効果を高める（ラットで出血量 0.87 vs 2.26 mL, p=0.012）が、**3か月後の残存塊が単独の1.7倍に増大する**（2289 µm → 3850 µm, p<0.001。著者は "could compress the surrounding tissue" と結論）[120]。

**使いどころ**: 人工血管吻合部（胸部大動脈・弓部分枝、2020年3月に「脳血管を除く血管全体の吻合部」へ適応拡大）の**補助的止血**。プロタミン後、乾いた面に薄く。
**使ってはいけない場面**: 血管内腔、静脈系の陰圧下、感染・汚染吻合部、脳血行再建、閉鎖腔への大量塗布、**縫合の代わり**。

### 2.9 PEG系ハイドロゲル（CoSeal / デュラシール）

**結論を先に**: **心臓・大血管の吻合部シーリングに使えるPEGハイドロゲルは、日本には無い。** 唯一の国内承認PEG製品デュラシール ブルースプレー（承認番号 22100BZX00895000、償還価格62,200円）は**脳神経外科の硬膜専用**（心大血管は適応外）であり、**2025年10月で受注受付終了**した。CoSeal・Progel・Adherusは検索範囲内で国内承認を確認できなかった。以下は**日本では現時点で適用できない海外知見**である。

**原理**: 2液の合成PEGが求核置換で共有結合架橋し、5秒（CoSeal）／3.5秒（デュラシール）でゲル化。**生物由来成分ゼロ、患者の凝固能に一切依存しない**（CoSeal IFU: "It works independently from the patient coagulation"）。ただし**「凝固能非依存 ≠ 出血していても効く」**。適用前に**吸引・乾燥が必須**であり、これは**「止血材」ではなく「止血後の再出血を防ぐ封止材」**である。

**エビデンス（外挿の限界を明示）**
- Glickman RCT（n=148、ePTFEグラフト）: 10分シール成功 86% vs Gelfoam/トロンビン 80%（**p=0.29、有意差なし**）だが、**即時シール 47% vs 20%（p<0.001）**、止血時間中央値 16.5秒 vs 189.0秒 [84]。→「最終的な止血率は同等だが圧倒的に速い」。**置き換えの根拠は「速度」であって「止血率」ではない。**
- Hagberg RCT（n=54/86吻合、腹部大動脈Dacron）: 即時シール 81% vs 37%（p=0.002）[85]。
- **⚠️ 「Bentall手術でCoSealのRCTがある」は誤りである。** Bentallの報告（n=102）は**後ろ向きcase-control**であり、著者自身が前向き試験の必要性を結論している [86]。**胸部大動脈・大動脈基部・弓部の吻合部シーリングを対象としたPEGシーラントのRCTは、検索範囲内に存在しない。**

**心臓外科医にとって最も実用的な事実**: **膨潤である。** CoSeal IFUは24時間で最大4倍に膨潤するとし、**市販後有害事象として「VAD（補助人工心臓）の閉塞」および「小児症例における製品の膨潤による心タンポナーデ」を明記**している（累積0.1%未満、メーカー資料）。脳神経外科ではDuraSealによる馬尾症候群（**全除去しても神経機能は回復せず**）[89]、禁忌部位使用による四肢麻痺 [90] が症例報告されている。**将来PEG製剤が国内導入されても、LVAD周囲・小児縦隔・胸骨直下の狭い空間への大量塗布は避けるべきである。**

**「シールできる」と「臨床転帰が改善する」は別問題**: 内視鏡下頭蓋底再建のネットワークメタ解析（27研究、n=2,403）で、**シーラント使用は術後CSFリークを減らさなかった**（risk difference 0.02, 95%CI −0.01〜0.05）[91]。**シーラント全般に通じる教訓である。**

### 2.10 シアノアクリレート系

**日本で使えるもの**: アロンアルフアA「三共」（**医薬品**、効能「生体組織（皮膚、血管、臓器など）の創傷癒合」）、ヒストアクリル（**医療機器**、血管内塞栓＝特定保険医療材料 区分145）、ダーマボンド系（一般医療機器、**皮膚表面専用**）、VenaSeal（下肢静脈瘤専用）。**Glubran 2は日本未承認。**

**原理**: モノマーが組織の水分を開始剤にアニオン重合して硬化。**凝固カスケードに一切作用しない。** in vitro接着強度は nBCA 0.62 MPa に対しフィブリン糊 0.02 MPa、GRF 0.1 MPa と**桁違いに強い** [99]。

**デメリット**
- **組織毒性**: nBCAは軟骨細胞に95%の細胞死を誘導し、細胞死は表面から100–150 µmの深さに及んだ（in vitro）[99]。
- **重合熱**: 添付文書が「大量使用により重合熱が発生する危険性」を明記。
- **動脈壁の菲薄化**: ウサギ腹部大動脈に塗布して3か月後、CA群で**大動脈壁の菲薄化**（弾性を持つ新規sealant群では菲薄化なし）（動物実験）[98]。
- **冠動脈吻合部での異物反応**: ブタoff-pump LITA-LAD吻合の比較で**NBCA群は4吻合中1本閉塞、中等度の異物反応**。**GRFが最良、BioGlueが最悪**とされ、著者は「シアノアクリレートよりGRFが優れる」と結論（JTCVS掲載）[97]。→ **CAが心血管でGRF/BioGlueより優れるというデータは存在しない。**
- **ホルムアルデヒド放出**: 市販医療用CA全製剤から放出が検出された（ピークは重合後2週以内、0.05–0.17% w/w）（in vitro）[100]。
- **添付文書上の禁忌**: **血管の全周性使用は禁止**（動脈狭窄・閉塞性血管病変の報告）、**不織布へのコーティング禁止**。→ **心臓外科でしばしば行われる「フェルト＋糊で縫合線を巻く」使い方は、CAでは添付文書に反する**（PGAフェルト＋フィブリン糊とは正反対の作法である点に注意）。

**使いどころ**: (a) **胸骨創の皮膚閉創** — 2-octyl CA + メッシュテープ vs 吸収糸＋防水ドレッシングのPSM（n=10,676）で60日創合併症 **3.47% vs 3.47%（p=0.996）**、**在院日数 9.2 vs 10.6日（p<0.001）、総費用も低い** [94]。ただし**SSI予防効果は証明されていない**（RCT n=996でSSI 4.9% vs 8.3%, p=0.16, 有意差なし [95]；前向きレジストリで縦隔炎に差なし [96]）。(b) 術後合併症（仮性瘤・エンドリーク）に対するIVRでのNBCA塞栓。
**使ってはいけない場面**: 心筋・大動脈縫合線への「一次止血材」としての使用（**心臓外科でのRCTは存在しない**）、血管の全周性塗布、不織布への含浸。

### 2.11 補強材（PGAフェルト・テフロンフェルト・心膜パッチ）

**これらは止血剤ではない。** 単独では凝固に何も作用せず、①糸のcheese-wiring防止、②シーラントの担体、③（PGAのみ）組織再生の scaffold として機能する受動的支持体である。

**日本で使えるもの**: ネオベール（PGA、グンゼ。使用目的は「縫合部・欠損部・脆弱部の補強、及び空気漏れの防止」であり**「止血」ではない**）、Bard PTFE布（メディコン、一般的名称「中心循環系心血管用パッチ」）、XenoSure等のウシ心膜パッチ、自己心膜。

**エビデンス**
- **「PGAフェルト vs テフロンフェルト」を主要評価項目としたRCTは存在しない。** 最良のデータはPSM研究1本（bFGF含浸PGAフェルト 67例 vs PTFE 129例、PSM 60ペア、中央値4.8年）: **院内死亡・合併症・吻合部瘤発生率（両群1.7%）に差なし。吻合部近傍の拡張率は PGA 2.5±0.5% vs PTFE 4.3±0.6%（p=0.01）でPGAが小さい** [102]。
- **PTFEフェルトの外周ラッピングは有害**（イヌ下行大動脈3か月で中膜厚 66%、外膜血管数 6.4 vs PGA 19.0/mm²、破断応力も低下）[105]。**"締め付ける" 使い方は避ける。**
- **「フェルト＋糊」の是非は術式に依存する**: 大動脈基部への**PTFE felt inlay＋糊**はATAAD 91例（IPTW）で**再手術ハザード比 8.38（1.63–43.0）**（40%が再解離／仮性瘤で再手術）[103]。一方、**内外PTFEストリップ＋フィブリン糊による supracoronary reconstruction は546例の後ろ向きで10年 event-free 95.1%、10年 pseudoaneurysm-free 99.8%** [104]。真っ向から対立する成績であり、**術式（inlayか内外ストリップか）と糊の種類が結果を分けている可能性がある。**
- **フェルトも糊も使わない直接吻合でも成績は出る**（ATAAD 94例で30日死亡4%、5年まで吻合部仮性瘤ゼロ）[107]。**「フェルトが必須」という前提自体が検証されていない。**
- **塗布法**: ブタ肺ex vivoで「フィブリノゲンを組織にrubし、トロンビン液を含ませたPGAフェルトを貼付する **Rub + Soak B法**」が単純スプレー・サンドイッチ法より有意に高い seal-breaking pressure を示した [—]。**フェルト厚は 0.15 mm が 0.3/0.5 mm より優れ、ORCは最も劣った** [—]。「乾いたフェルトを載せてスプレー」は劣る。
- **PGAシート＋フィブリン糊はTachoComb単独より接着強度・破裂圧が有意に高い**（ex vivo）[108]。実務的裏技として引用可能。

**正直な陰性所見**
- **「テフロンフェルトによる弁尖障害」を示す臨床報告は、検索範囲内で見つからなかった。** 近縁の所見は基部フェルト＋糊使用例での吻合部・洞の再解離やAR進行に留まる。**現時点でエビデンスとして主張できない。**
- **フェルト由来の人工物感染（縦隔炎・グラフト感染）の頻度を定量した臨床研究も見つからなかった。** 根拠は添付文書のリスク列挙のみ。

**注意**: PTFEフェルトは**260℃以上の高温器具（電気メス等）との接触禁止**（添付文書）。

## 4. 安全性 — 「無理やり止める」ことの代償

### 4.1 Hydrofit（ハイドロフィット）: 仮性動脈瘤と感染の懸念を検証する

**臨床現場からの指摘**: 「Hydrofitで止血した症例に、後から仮性動脈瘤が目立つ気がする」。
本節は、この指摘に対して**文献が何を言っていて、何を言っていないか**を正直に書く。結論を先に述べる。

> **「Hydrofitが仮性動脈瘤を起こす」ことを支持する文献は、PubMed・J-STAGE・Web検索のいずれにおいても1件も存在しない。同時に、これを否定できるだけの検証も、世界に1本も存在しない。**
> **ただし、日本の添付文書は〔重大な有害事象〕として「仮性動脈瘤」を明記している。**
> **これは「安全である」とも「危険である」とも読んではならない。誰も調べていない、というのが正確な現状である。**

#### (1) 文献の総量 — まず土俵の広さを知る

PubMedで `Hydrofit OR AQUABRID` を検索して**22件**（うち1件は同名の無関係な計算ソフト）＝実質**21件**。

- 〔**重大な有害事象**〕欄: 死亡、多臓器不全、縦隔炎、心不全、滲出液又は漏出液の貯留、心タンポナーデ、出血、感染、発熱、心膜炎、**仮性動脈瘤**、血栓塞栓症。

**これをどう読むか（捏造を避けるための厳密な言い方）**:
- これらは「**因果関係が否定できない**」有害事象の**列挙**であり、**Hydrofitが仮性動脈瘤を惹起したことを示すものではない**。吻合部仮性瘤は胸部大動脈置換術そのものの既知の遠隔期合併症であり、単群・対照なしの安全性データベースでは背景発生率と区別できない。
- 「仮性動脈瘤（**前回中枢側吻合部**）」という記載に至っては、**前回手術の吻合部**の仮性瘤であり、Hydrofitとの時間的・空間的関連はむしろ乏しい。
- したがって言えるのは **「規制文書に有害事象として列挙されている」以上のことではない**。**因果を示す比較研究は存在しない。**

#### (3) 判定: **NO_EVIDENCE（証拠なし）**。しかしこれを「安全の証明」と読み替えてはならない

その理由を5つ、明示する。

1. **仮性動脈瘤をアウトカムとして設定した研究が1本もない。** 542例のPMSですら評価項目に含めていない [118]。
2. **Hydrofit使用群 vs 非使用群で系統的CT追跡を行った比較研究はゼロ。** 発生率を論じる土台がない。
3. **追跡期間が短い。** PMSの規制要件上の追跡は1年。**BioGlue/GRFの仮性動脈瘤は術後24〜65か月（GRFでは平均30±18か月）に出現する** [68,69,70]。**Hydrofitの市販後追跡は、遅発性合併症が「出るはずの時期」を系統的にカバーしていない。**
4. **報告バイアス。** 論文の大半が開発者・製造元コンサルタント・熱心な使用者によって書かれており、陰性所見がpublishされにくい構造がある。
5. **止血剤の有害事象は系統的に過小報告されている。** 186 RCTを統合したNIHR HTAは *"Adverse events were **inappropriately reported** in observational studies."* と結論している [6]。

> **Absence of evidence is not evidence of absence.**
> 本レビューは、現場の観察が誤りであるとは主張しない。**検証されていない、というのが正確な現状である。**

#### (5) BioGlue/GRFの前例を外挿できるか → **できない（が、教訓は使える）**

- **化学が違う。** BioGlue/GRFの仮性動脈瘤機序は**アルデヒドによる組織固定＝中膜平滑筋の細胞死**（ヒト病理で「中膜平滑筋核の消失」として確認されている [68]）と、**組織より遥かに硬い糊（3,122 kPa vs 大動脈）によるコンプライアンス・ミスマッチ** [64] である。Hydrofitはイソシアネート–水反応であり、アルデヒドを放出しない。**in vitroでは、Hydrofitは BioGlue と同等の接着強度を持ちながら破断までの伸長率・最大応力が有意に高い（＝より柔らかく伸びる）** [117]。**力学的病因については、Hydrofitは理論上有利である。**
- **しかし「別の化学的病因を持たない保証」もない。** ジイソシアネート系プレポリマーの分解産物の組織毒性を評価した研究は、検索範囲内に存在しない。
- **そして BioGlue ですら、集団レベルでは仮性動脈瘤を増やしていない**（CT追跡177例で0.6%）[74]。**「接着剤だから仮性動脈瘤を起こす」という一般化は、それ自体が誤りである。**
- **使うべき教訓は「型」である。** GRFは導入（1977）から撤退宣言（2000）まで23年を要し、その間ずっと「短期成績は良い」というデータが積み上がっていた [69]。**短期の止血効果は、長期の安全性の代理指標にならない。止血に成功した患者こそが、3年後に再手術を受ける患者である。**

### 4.2 接着剤の組織毒性の前例 — GRF糊とBioGlueが教えたこと

**一行で言えば**: *アルデヒド架橋型接着剤は「短期の止血・手術容易性」と引き換えに「遅発性の壁壊死・再解離・仮性動脈瘤」を買う取引だった。GRFはその代償が大きすぎて捨てられ、BioGlueは代償を小さくしたが消してはいない。*

**病態生理の連鎖（推論を含む）**: アルデヒドが組織蛋白のアミノ基と共有結合 → 中膜平滑筋細胞が固定＝細胞死 → リモデリングできない死んだ膠原線維の板になる（**急性期には硬くて縫いやすい＝術者が体感する「効いている」感覚の正体**）→ 硬い糊と拍動する大動脈のコンプライアンス・ミスマッチで境界に応力集中 → 数か月〜数年で離開 → 再解離／仮性動脈瘤。再手術所見の「**GRF塗布部が変性し、根部–人工血管吻合が広く離開していた**」[69] はこの帰結そのものである。

**GRFのin vitro最適化データ**（活性化剤/接着剤 = 1:10 で接着力はほぼ最大に達し、それ以上の活性化剤は「残余・潜在的有害」）は、**「多めに垂らす分は接着に寄与せず毒性だけを足している」**ことを定量的に示している [—]。**これは全ての接着剤に共通する教訓である。**

### 4.3 感染・異物反応

**厳密な切り分け**:

| 主張 | 証拠 | 判定 |
|---|---|---|
| ゼラチン系が汚染創で感染を増強する | ラット汚染腹部創モデル（n=170）で**ゼラチンマトリックス群の感染率 87%**、無処置 14%、多糖類（Arista）24% [136]。Gelfoam添付文書 *"may serve as a nidus of infection and abscess formation, and has been reported to potentiate bacterial growth"* | **動物・メーカー資料レベルで支持**。ヒト心臓外科への外挿は未検証 |
| BioGlueが強い異物反応（肉芽腫・無菌性膿瘍）を起こす | 動物（ウサギ大動脈で炎症スコア 2.67 vs CoSeal 1.56, p=0.002、好酸球浸潤）[87]、ヒト病理（人工弁sewing cuff上のpannusがBioGlue そのもの＋弁輪部膿瘍）[147]、小児脳外科13% [81] | **異物反応はSUPPORTED。細菌感染そのものの増加はWEAK** |
| ORCが縦隔炎リスクを上げる | 縦隔炎アウトブレイク時の後ろ向きコホート（n=87）で使用頻度と感染リスクに線形関係（3.3%→22.6%, P=0.024）、**製品中止後1年間で新規発生ゼロ** [54] | **WEAK**（エコロジカル解析。ただし用量反応と中止後の消失は無視できない） |
| ORCが臨床で感染を減らす（"bactericidal"の臨床的意義） | in vitroと1970年代の動物実験のみ。**添付文書自身が「in vitroで抗菌性を有するとの報告があるが、術後感染防止などのために全身投与される抗菌剤に代わるものではない」と明記** | **NO_EVIDENCE** |
| フィブリンシーラントが感染を増やす | **FIBER RCT（n=1,445）で縦隔炎を副次評価項目に設定し、有意差なし** [4] | **REFUTED に近い** |
| **止血剤が画像上、感染・腫瘍再発と誤診される** | 症例報告多数（心臓外科では人工弁感染性心内膜炎 [47]、perigraft abscess [48]、新生児の縦隔炎誤診→早期再開胸 [49]）＋前向きコホートで縦隔リンパ節腫大の8%が異物肉芽腫 [51]＋**添付文書に明記**（「異物反応により本剤の被包化、肉芽腫形成等が生じ、これらの構造物が画像上、腫瘍、膿瘍等に類似し、誤診や再手術につながったとの報告がある」） | **SUPPORTED** |

> **総括**: 「異物 → 感染」は生物学的妥当性としては十分に成立するが、**心臓外科の患者アウトカムとしては、ORCと縦隔炎を結ぶ低質な観察研究1本を除き実証されていない**。**臨床的に確実な害は「感染」ではなく「感染の誤診」である。**

**最も費用対効果の高い対策（複数論文の一致した推奨）**:
1. **手術記録に止血剤の種類と留置部位を明記する。**
2. **術後CTで「気泡を伴うperigraft collection = 必ずしも感染ではない」ことを放射線科医と共有する。**

### 4.4 クラス別の重篤有害事象

#### (a) 空気／ガス塞栓（フィブリン糊の加圧スプレー）— **規制当局レベルの警告**
- FDA添付文書（EVICEL）: *"Life-threatening air or gas embolism has occurred with the use of spray devices employing a pressure regulator..."*
- MHRA: 世界で計10例の生命を脅かす／致死的な空気塞栓（Evicel 5、Tisseel 1、Quixil 4）。**いずれも推奨より高圧・近接での使用に関連。**
- NIHR HTA: 規制当局の5件の報告で**死亡**が記載 [6]。

| 製品 | 開放手術：最大圧／最小距離 | 腹腔鏡 |
|---|---|---|
| Evicel | 1.7 bar (25 psi) / **10 cm** | 1.4 bar / 4 cm |
| Tisseel | 2.0 bar (28.5 psi) / **10 cm** | 1.5 bar / 2 cm |
| Artiss | 2.0 bar / 10 cm | 使用非推奨 |

**心臓外科での実務**: 噴霧ガスは**空気ではなくCO₂**。**噴霧中はEtCO₂・SpO₂・血圧・心拍を監視**（EtCO₂の急落＝ガス塞栓のサイン）。**心腔・大血管が開放された術野への高圧スプレーは特に危険。**
※**ボルヒール／ベリプラストPの日本語添付文書には bar/cm の数値規定が見当たらず、上表は欧米（FDA/MHRA）の規定である。国内スプレーデバイスの添付文書には「加圧ガスが送気されているのでガス塞栓症の発症の危険性に十分留意し、閉鎖系での使用とならないよう注意する」旨の記載がある。**
※**Hydrofitも硬化時にCO₂を発生する**が、**これに起因するガス塞栓の報告は検索範囲内で1件も見つからなかった**。添付文書は「切開手術以外の術式における使用は避けること」と規定している [124]。

#### (b) 血管内迷入・遠隔塞栓 — **剖検で確定した致死例が複数ある**
| 製剤 | 転帰 |
|---|---|
| ゼラチン系止血マトリックス | 頸椎手術2例。術後に神経脱落 → 脳梗塞。**剖検で椎骨脳底動脈に止血材と一致する異物を含む血栓塞栓を確認。両例とも死亡** [132] |
| ウシゼラチン顆粒＋ヒトトロンビン | L5神経鞘腫摘出後8時間で呼吸困難・右心不全 → **死亡。剖検で左肺動脈が完全閉塞、塞栓の組織学的主体はゼラチン顆粒** [132] |
| フィブリン糊（**心臓外科**） | Marfanの**弁温存大動脈基部置換**。糊が針穴からValsalva洞内に漏入し、**左冠尖の心室側に可動性膜様構造として付着**。術中TEEで発見し、大動脈を直ちに遮断のうえ摘出・弁形成やり直し [131] |

#### (c) 冠動脈入口部の外部圧迫 — **接着剤に固有の、心臓外科で最も注意すべき「圧迫」**
- **ゼラチン／ORC系による冠動脈グラフト・冠静脈洞・移植心の圧迫は、検索範囲内で1件も見つからなかった**（NO_EVIDENCE。心嚢が骨性の閉鎖腔ではないためと考えられるが、これは推測）。
- **一方、接着剤による冠動脈入口部の外部圧迫狭窄は複数報告されている（SUPPORTED、症例報告の集積）**:
  - modified Bentall後の**BioGlueによるLMCA外因性狭窄** → IVUSガイドPCIで治療 [76]
  - Valsalva洞の偽腔をBioGlueで再接着（**スポンジを内腔に入れて糊の侵入を防ごうとした**）→ 術後CTでLMT狭窄 → **DCAで摘出、病理でBioGlueと確認**。著者結論: 「**スポンジを入れても糊の侵入は防げなかった**」[77]
  - modified Bentall＋**GRF**による冠動脈再建 → 7週後に**両冠動脈入口部が硬い線維性物質で圧迫**され重症虚血。**ステント留置は無効**で外科的冠動脈再建を要した。結論: 「**Bentallの冠動脈再建に糊を使うべきではない**」[78]
- **実務**: **冠動脈ボタン周囲・Valsalva洞に糊を大量に置かない。** 基部手術後の説明のつかない心筋虚血では、**糊による外部圧迫を鑑別に挙げてCT/IVUSで評価する。**

#### (f) ウシトロンビンによる抗第V因子抗体（**主として米国の問題**）
- FDA **BOXED WARNING**（Thrombin-JMI）: *"can cause fatal severe bleeding or thrombosis... Bleeding may result from the development of antibodies against factor V. These may cross-react with human factor V."*
- Phase 3 RCT（n=305）: **抗体陽転はウシトロンビン 12.7% vs ヒト血漿由来トロンビン 3.3%**、止血効果は同等（10分止血 97.4% vs 97.4%）[133]。rhThrombin では抗体産生 0.8〜0.9% かつ**中和活性なし** [134]。
- **日本の実務**: 心臓外科で使うフィブリン糊・フロシール・サージフローの**トロンビン成分はいずれもヒト由来**であり、このリスクは主として米国の話。ただし**トロンビン液モチダ等の単剤はウシ由来**であり、「術後に説明のつかない出血＋PT/APTT延長＋第V因子活性低下」を見たら**ウシトロンビン曝露歴を問診する**。

#### (g) 血液製剤としてのリスク（規制上の義務）
- **ボルヒール・ベリプラストP・タコシール・フロシール・サージフローはすべて特定生物由来製品**。→ **販売名・ロット番号・使用年月日・患者氏名住所を記録し、少なくとも20年間保存する法的義務**がある。
- 添付文書は「検出限界以下のウイルスが混入している可能性は常に存在する」と明記（特にパルボウイルスB19）。**実際の伝播事例は検索範囲内で見つからなかった＝理論的リスク。**
- **Hydrofit・サージセル・アリスタAH・シアノアクリレートは生物由来成分を含まない**（記録義務なし）。

#### (h) 過小報告という背景問題
> NIHR HTA（186 RCT + 8観察研究）: *"Adverse events were **inappropriately reported** in observational studies."* [6]
> **本レビューで「報告が見つからなかった」項目は、「安全」を意味しない。**

さらに、警鐘として: Tissucol Duo S を用いたCABG 2,149例の後ろ向き解析で、**30日死亡率 8.5%（糊使用879例） vs 3.5%（非使用1,270例）, p<0.001**、多変量調整後もOR 2.2を下回らなかった [135]。**これは適応交絡（出血している症例ほど糊を使う）を否定できない後ろ向き研究であり、因果ではない。** しかし「糊は無害だから念のため塗る」という発想への警鐘として記憶に値する。

### 5.3 算定要件 — ここが術者の意思決定を決める

**区分106（微線維性コラーゲン）留意事項通知（原文抜粋）**:
> 微線維性コラーゲンは、…**大動脈切開縫合吻合部（人工血管を含む。）、心臓切開縫合閉鎖部、心臓表面、ＡＣバイパス吻合部、胸骨断面**、肺切離面…からの出血で、**結紮、レーザーメス又は通常の処置による止血が無効又は実施できない場合**において、止血に使用した場合に算定する。

→ **大動脈吻合部・心臓表面・CABG吻合部・胸骨断面は明示的に算定対象。ただし「結紮や通常処置で止血が無効／実施不能」という条件が付く。ルーチンの予防的散布は算定要件を満たさない建前であり、記録上の裏付けが必要である。**

### 5.5 経営的視点 — 誤解を正す

1. **「高価な止血材を使うと病院が損をする」という直感は、心臓外科では多くの場合誤りである。** 主要な止血材のほぼすべてが特定保険医療材料または薬価収載品として償還される。**唯一の例外がゼラチンスポンジ**（心臓外科では算定不可）であり、これは皮肉にも最も安価な材料である。
2. **償還価格 ≠ 病院の購入価格。** 購入価格は入札・値引きで下がり、その差額が病院の利益になる（国循の2017年調達リストでは BioGlue 10 mL の定価155,000円に対し落札単価132,000円、償還価145,800円）。
3. **正しい論法は「高いから使わない」ではなく「効かないから漫然と使わない」である。** 再開胸1件の増分コストは **€6,290**（うち48%が在院延長、31%が手術／麻酔、20%が輸血。**止血薬剤費は2%未満**）[11]。**「止血剤で1件の再開胸を防げるなら €6,290 までは正当化される」が、その「再開胸を防ぐ」というエビデンスが無い**というのが本レビューの核心である。
4. **FIBER試験の経済評価**（本領域で最も信頼できる独立した経済評価）: CryoSeal は **€822/例**、**1回の輸血回避あたり €72,000**。「ルーチン使用を支持しない」[4]。
5. **算定要件の「結紮又は通常の処置による止血が無効」という文言は、査定・監査上の潜在的な弱点である。** 予防的散布を常態化させている施設は、記録の整合性を点検すべきである。

**未確認事項（正直に）**: **ハイドロフィットの償還区分は、令和8年度材料価格基準の全区分（001〜217）を検索した範囲では特定できなかった。** 区分166(2)「外科用接着用材料・特殊型」（28,800円/g）が該当する可能性はあるが、**これは推測であり一次情報での確認が取れていない。院内の医事課／メーカーに確認されたい。** 同様に、フロシール／サージフローの区分106への割当て、アリスタAHの区分151への割当ては Confidence MEDIUM である。

### 6.1 ハードエンドポイントを改善した証拠はあるか → **無い**

| **Daud メタ解析** [5] | SR＋メタ解析（GRADE）、**心臓・血管外科に限定**。21研究 n=7,622（RCT 13） | 出血量 **MD −120.7 mL**（moderate quality）、止血時間 **MD −2.5分**（**low quality**）。**術後輸血・出血による再手術・30日死亡は有意差なし。** 結論: *"clinically small reduction… support **selective rather than routine use**"* |

### 6.2 代替エンドポイントの脆弱性 — コーパスから拾える4つの具体例

| 現象 | 証拠 |
|---|---|
| **同じ製品が試験によって全く違う成績を出す** | FloSealの3分止血成功率: **72%**（Fusion Matrix [12]） vs **9.6%**（HEMOBLAST比較試験 [14]）。後者は「デバイス準備時間」を計時に含める設計 |
| **「止血時間の有意差」が添付文書の推奨貼付時間の差でしかない** | Veriset vs TachoSil: 中央値 1.5分 vs 3.0分（p<0.0001）。だが**推奨最短貼付時間が30秒 vs 3分**。**著者自身が「3分時点で直接比較すると有意差なし」と明記**。両群とも再手術ゼロ [19] |
| **対照群が「ガーゼ圧迫」** | HEMOPATCH RCT [20]、TISSEEL Lyo試験。用手圧迫を3〜4分でやめた場合の止血率（20〜66%）を分母にした「優越性」 |
| **天井効果** | Collastat vs FloSeal（OPCAB二重盲検RCT）: **両群とも止血成功 97.5〜100%** [15]。この土俵ではどの製品も差が出ない |

**STS 2021 が自ら書いていること**（原文）[1]:
> *"Despite widespread use in cardiac procedures over many years, **no single topical preparation emerges as the agent of choice**... **the source of bleeding and the patient's coagulation profile are important factors that may preclude the actions of any and all topical hemostatic agents**. **Assessment of topical hemostatic agents in clinical RCTs is extremely difficult due to difficulty in establishing reliable end points**..."*

### 6.3 ガイドラインの実際の文言

| ガイドライン | 局所シーラント／止血剤への推奨 |
|---|---|
| **STS/SCA 2011** [7] | *"Topical hemostatic agents… **may be considered** to provide local hemostasis at anastomotic sites as part of a multimodal blood management program."* — **Class IIb, Level C** |
| **STS/SCA/AmSECT/SABM 2021** [1] | **局所シーラント／止血マトリックスに対する推奨は削除された。** "TOPICAL HEMOSTATIC AGENTS" セクションに残る推奨は**局所抗線溶薬（Class IIa, Level B-R）のみ**。一方、**粘弾性試験を組み込んだ目標指向型輸血アルゴリズムは Class I, Level B-R** |
| **2017 EACTS/EACTA** [2] | *"**Routine use of topical sealants in cardiac surgery is not recommended.**"* — **Class III, Level B**（引用文献＝FIBER試験）<br>*"Topical sealants **may be considered** in clinical situations where conventional approaches… have failed and where bleeding problems are **more local than generalized**."* — **Class IIb, Level C** |
| **2024 EACTS/EACTAIC/EBCP** [3] | **スタンスは不変**: *"Based on the available evidence, the **routine use of topical sealants in cardiac surgery is not recommended** and may only be considered in cases of persistent bleeding where **haemostasis cannot be achieved with mechanical haemostatic agents in the absence of coagulopathy**."*<br>※2024版の推奨表のClass/Level文字列はPMC上で画像であり、**一次資料から直接確認できなかった**（本文の "not recommended" 記載のみ確認済） |
| **SABM 国際専門家パネル** [8] | 「詳細な指針が存在せず**使用にばらつきがある**」という問題意識から招集。**エビデンスレベルは「専門家意見」**であり、学会の正式ガイドラインとは階層が異なる |
| **日本のガイドライン** | **2020年改訂版 大動脈瘤・大動脈解離診療ガイドラインを含め、局所止血剤・シーラントの使用を推奨/非推奨する推奨クラス・エビデンスレベル付きの記述は、検索範囲内で見つからなかった。** → **日本では、これらの使用はガイドラインではなく添付文書と施設慣行に依拠している** |

**2024年版で加わった重要な変更**: **DEPOSITION RCT**（心臓外科3,242例）で、**局所TXAは静注TXAに対し痙攣を減らさず、輸血必要性を8.3%増加させ、安全性を理由に早期中止**された [139]。→ **「局所投与だから安全」という前提すら成立しない。**

### 6.4 産業スポンサーバイアス — 「同じデータベースから正反対の結論」

| 研究 | スポンサー | 結論 |
|---|---|---|
| Tackett 2014（Premier、FloSeal 4,480 vs Surgiflo 326）[16] | **筆頭著者がBaxter（FloSeal）社員** | **Surgifloが劣る**: 大合併症 OR 2.12、再手術 OR 2.01、**輸血 OR 4.90**、手術時間 +64分 |
| Danker 2022（**同じPremier**、PSM 5,768組）[17] | **筆頭著者がEthicon（Surgiflo）社員** | **ほぼ同等**: 出血イベント 6.9% vs 7.2%（P=0.576）。**Surgifloの方が入院費が安く、再入院オッズも低い** |
| Wan 2017（Premier、EVICEL 986 vs TISSEEL 6,340）[18] | **著者がEthicon（EVICEL）社員** | **EVICEL優位**: 出血合併症 3.0% vs 5.0%、**30日再入院 18% vs 32%（p<0.0001）** |

**読み方**: 同一のPremierデータベースを、propensity score matching という同一手法で解析しながら、**スポンサーの製品が常に勝つ**。EVICEL vs TISSEEL の「再入院 18% vs 32%」という14ポイント差は、局所止血剤の選択で説明できる大きさとは考えにくく、**残余交絡（施設・術者・出血の重症度）の存在を強く示唆する。**
> **これらのdatabase研究・cost-consequenceモデルを、製品選択の根拠にしてはならない。**

費用対効果研究も同様である。FloSeal優位の英国NHS経済影響モデル（100例あたり£178,283の節減）は**著者3名全員がBaxter社員**、Hemopatchの費用対効果モデル（ICER €1,440–1,659/止血成功）は**ICERの分母が「止血成功」という代替アウトカム**で、入力データは単一の非盲検RCT（対照＝ガーゼ圧迫）のみ。**企業非関連で「増加」を報告したのはフランスの前向き観察研究1本だけ**（糊使用群の方が輸血単位数・ICU滞在が有意に長く、入院費も高い。ただし**適応交絡の典型**）[138]。

### 6.5 Overuse について — 正直な記載

> **「心臓外科において局所止血剤が overuse されている」ことを定量的に示したデータベース研究は、本検索範囲内には見つからなかった。**

存在するのは、(a) 学会が「**使用にばらつきがある**」と認めている事実 [8]、(b) 使用が増えているという製品レベルのutilization研究、(c)「糊使用群の方が転帰・コストが悪い」という交絡した観察研究 [138,135] である。
ただし、**EACTSがClass IIIで「ルーチン使用を推奨しない」と明示している以上、予防的散布/貼付を常態化させている運用は、それ自体がガイドラインからの逸脱である。**

### 6.6 止血剤より強いエビデンスを持つ介入

| 介入 | 推奨/効果 |
|---|---|
| **粘弾性試験（TEG/ROTEM）ガイド下の目標指向型輸血アルゴリズム** | **STS 2021: Class I, Level B-R** [1]。Cochrane 2026（35 RCT、n=3,096、大半が待機的心臓外科）: **死亡 RR 0.76（0.63–0.92）、外科的再介入 RR 0.63（0.45–0.88）、FFP RR 0.52、血小板 RR 0.69**（ただしGRADEは全アウトカムで very low certainty）[9] |
| **制限的赤血球輸血戦略** | **STS 2021: Class I, Level A** [1] |
| **術中止血チェックリスト** | 4研究 **19,946例**。**チェックリスト導入で出血による再開胸率が有意に減少**、3研究でコスト・輸血・ICU滞在も減少 [10]。**「無料の介入」で再開胸が減る** |
| **CPB中の正常体温（>36℃）・正常pH（7.35–7.45）** | **EACTS 2017: Class IIb, Level B** [2] |

| **局所止血剤・シーラント** | **EACTS: Class III（ルーチン使用は推奨しない）／Class IIb, Level C（局所性の遷延出血のみ）**。STS 2021 では推奨そのものが**削除** |

> **「再手術を減らす」ことについてRRを提示できているのは粘弾性試験であって、局所止血剤ではない。**

## 7. 実践的アルゴリズム（結局どう使うか）

### STEP 0 — 使う前に必ず済ませる（ここが最もエビデンスが強い）
1. **外科的止血**（縫合追加、フェルト補強、視野確保、圧迫）。
2. **ヘパリン中和の確認**（ACT／ヘパリナーゼTEG、プロタミン追加の是非）。
3. **体温 >36℃、pH 7.35–7.45 の是正** [2]。
4. **粘弾性試験ガイド下の目標指向型補充**（フィブリノゲン、血小板、FFP/PCC）— **Class I, Level B-R** [1]。
5. **術中止血チェックリストの運用** [10]。
6. **↑ が全て済んで、なお「局所性」のoozingが残る場合にのみ局所止血剤**（EACTS: ①凝固障害がない ②機械的止血が尽きた ③出血が局所的、の3条件）[3]。

### STEP 1 — 出血の性状で分ける

**A. 拍動性・噴出性（動脈性）**
→ **止血材はどれも無効。ORC・微線維性コラーゲン・フロシール／サージフローは、いずれも添付文書上の禁忌である。**
→ 縫合／フェルト（＋プレジェット）／パッチが唯一の答え。
→ 吻合部を遮断して乾かせる場合に限り、**接着剤（バイオグルー／ハイドロフィット）で「機械的に封止」する**選択肢がある。ただしそれは止血ではなく補強であり、**縫合の代わりではない**（両製品の添付文書に明記）。

**B. 針穴（needle hole）出血・吻合線**
→ **フィブリン糊**: A液をガーゼで**擦り込み（rub）**、B液を重ね、**2分以上待つ**（滴下・単純噴霧・30秒硬化は有意に劣る）[110,112]。
→ **PGAフェルト／テフロンフェルトを担体にする**と接着強度・破裂圧が上がる（"Rub + Soak B法"、フェルト厚 0.15 mm）[108]。**ORCを担体にしてはならない（トロンビン失活）。**
→ 乾かせるなら**ハイドロフィット**（人工血管への接着はin vitroでBioGlueより強い [117]）。ただし**必要最少量、2〜3倍に膨潤することを前提に。**

**C. 脆弱組織（急性A型解離の断端・偽腔、梗塞心筋）**
→ **フェルト＋糊**が日本の既定路線。ただし**術式で成績が分かれる**: 基部への **PTFE felt inlay ＋糊は再手術HR 8.38** [103] 一方、**内外PTFEストリップ＋フィブリン糊のsupracoronary reconstructionは10年 pseudoaneurysm-free 99.8%** [104]。**「取り囲む・詰め込む」使い方を避け、「面で支える」使い方にする。**
→ **フェルトも糊も使わない直接吻合でも成績は出る**（5年まで吻合部仮性瘤ゼロ）[107]。**「フェルトと糊は必須」という前提を一度疑う価値がある。**
→ **BioGlueを使うなら**: 薄く（幅2 cm×厚2 mm）、全周性に取り囲まない、真腔・冠動脈口・弁尖・洞房結節・横隔神経を物理的にブロック（**水溶性ゲルが動物実験で保護的** [67]）、塗布後2分待つ、内腔を洗浄・確認、**小児は禁忌、反復使用は禁忌**。

**D. 面状のoozing（心表面・胸骨断面・剥離面・心膜切開面）**
→ プロタミン後であることを確認。
→ **第一段**: サージセル（48円/cm²〜）または微線維性コラーゲン。**ただしセルセーバー使用症例ではアビテン／インテグランは添付文書上「禁忌」。** サージセルは**大動脈の出血部には禁忌**であり、**トロンビン系との重層は失活**する。
→ **第二段（不整形・深部・低圧系）**: フロシール／サージフロー。**遮断中の血管・拍動性出血・セルセーバー回収域は禁忌。20%膨潤するので余剰は必ず洗浄除去。**
→ **生物由来を避けたい症例**（宗教上の理由、ゼラチン／ウシアレルギー）: **アリスタAH**（ただし**ヘパリン化中はほぼ無効**、糖尿病患者は禁忌）。
→ **広い面をシールしたい**: タコシール（黄色面を創面に、濡らしすぎず、3〜5分圧迫）。

**E. 心破裂（LVFWR）**
→ **oozing type**: タコシール sutureless repair（＋PGAシート＋フィブリン糊で接着強度を上げる [108]）。
→ **blow-out type**: **貼るだけでは不十分**（re-rupture 17%、blow-out 2例は両方とも再破裂 [22]）。縫合・パッチ修復を。

### STEP 2 — 使った後に必ずやる
1. **余剰は洗浄・吸引で除去する**（全製品の添付文書）。
2. **手術記録に「止血剤の種類・留置部位・量」を明記する。** ← **最もエビデンスに裏打ちされた対策**（画像誤診による不要な再手術を防ぐ）。
3. **特定生物由来製品（ボルヒール／ベリプラストP／タコシール／フロシール／サージフロー）はロット番号・使用日・患者情報を20年保存。**
4. **バイオグルー使用歴は患者にも伝える**（反復使用は禁忌）。
5. **接着剤（BioGlue／GRF／Hydrofit）使用例は、遠隔期のCTフォローを組む。**
6. **弁温存基部置換・Bentallでは、離脱時TEEで「弁尖上の可動性構造物」を確認する** [131]。

### STEP 3 — 術後にトラブルが起きたら
- **原因不明の術中ショック** → アナフィラキシーを鑑別に。**トリプターゼを採血し、貼った/塗った止血材を物理的に除去して洗浄する。**
- **術後CTで「気泡を伴うperigraft collection」／縦隔の腫瘤／人工弁周囲のエコー源性腫瘤** → **まず手術記録を見る。** 残存ORC/ゼラチン/BioGlueが膿瘍・PVE・縦隔炎に見えることは確立した pitfall である [47,48,49]。
- **基部手術後の説明のつかない心筋虚血** → **糊による冠動脈入口部の外部圧迫**を鑑別に。CT/IVUS。**GRF由来ならステントは無効でありうる** [78]。
- **術後年単位の創部腫脹・排膿（培養陰性）** → **残存止血材による無菌性炎症**を鑑別に [122]。

| # | 問い | なぜ重要か |
|---|---|---|
| 1 | **Hydrofit使用群 vs 非使用群の、系統的CT追跡による吻合部仮性動脈瘤発生率の比較** | **本レビュー最大の知識ギャップ。** 「Hydrofit後に仮性動脈瘤が目立つ」という臨床印象を、支持することも反証することもできる文献が世界に1本もない。日本の使用実績（PMSだけで576例）を考えれば、**多施設後ろ向き研究で十分実施可能**である。追跡は最低3年（BioGlue/GRFの遅発性合併症は24〜65か月に出る）。**これは日本の心臓外科が世界に対して負っている宿題である。** |
| 2 | **Hydrofitの分解産物／イソシアネート系プレポリマーの組織毒性評価** | アルデヒドを使わないことは有利だが、**別の化学的病因を持たない保証はない**。現時点で評価した研究はゼロ |
| 3 | **PMDA医療機器不具合報告データベースの網羅的検索** | 本調査ではUIの制約で実施できなかった。**「不具合報告がない」とは言えない**状態が続いている |
| 4 | **心臓外科での局所止血剤の「使用 vs 非使用」を、再開胸・輸血・死亡を主要評価項目として検証するRCT** | NIHR HTAが名指しでgapとして挙げた [6]。FIBER試験（フィブリンシーラント、CABG）以外に存在しない。**特にORC・微線維性コラーゲンの「無処置対照RCT」は1本もない** |
| 5 | **日本人心臓外科患者を対象としたRCT** | フィブリン糊・フロシール／サージフロー・アリスタAHのいずれについても、**日本人心臓外科患者のRCTは存在しない**（すべて後ろ向き・前後比較・症例集積） |
| 6 | **タコシールの心臓外科における炎症・癒着・遺残のヒトデータ** | 当該領域のレビュー自身が「**存在しない**」と明言している [23]。再開胸を見据えた心膜面貼付の是非を判断する材料がない |
| 7 | **ORCの実測pH値と「トロンビン失活」の直接検証** | 併用禁忌の根拠が定性的記述と添付文書にとどまる。**「酸ヘマチン形成」という古典的機序を直接検証した一次文献も見つからなかった** |
| 8 | **セルセーバー併用下で微線維性コラーゲンを使った際の臨床アウトカム（腎障害・微小塞栓）** | **日本の添付文書は「禁忌」としているが、心臓外科の現実と正面から矛盾している。** 「アビテンを置いた領域は吸引しない」等の回避策の安全性は**未検証**である |
| 9 | **止血剤と縦隔炎・SSIを主要評価項目とした大規模比較研究** | 検索範囲内に存在しない。既存のPremier研究はすべて出血・輸血・コストが主眼で、**感染は評価項目ですらない** |
| 10 | **仮性動脈瘤レジストリ** | 接着剤（BioGlue/GRF/Hydrofit）使用の有無と遠隔期の吻合部イベントを紐づける前向きレジストリがあれば、GRFで23年かかった学習を、次の材料では5年に短縮できる |
| 11 | **PGAフェルト vs テフロンフェルトのRCT** | 最良のデータはPSM研究1本 [102]。「フェルト＋糊が必須」という日本の既定路線自体が検証されていない |
| 12 | **ハイドロフィット・ネオベール・テフロンフェルトの保険償還区分の確定** | 本調査では一次資料から確定できなかった。**償還されるか包括かで病院経営上の意味が変わる** |
| 13 | **国内でアプロチニンフリーの液状フィブリン糊が使えないことの臨床的インパクト** | Evicel/Vivostatが国内未承認であるため、**牛肉アレルギー・アプロチニン既曝露例で代替がない**。この制約下での実務指針は存在しない |

## 本レビューの限界（透明性のための注記）

1. **臨床データの大半は PubMed abstract に基づいており、フルテキスト精読は行っていない。** 数値はabstract記載値である。

5. **価格は2026年度（令和8年度）の公定価格である。改定のたびに変わる。** ハイドロフィット・ネオベール・フロシール／サージフロー・アリスタAHの機能区分の割当ては Confidence MEDIUM〜LOW であり、**院内の医事課／メーカーへの確認が必須**である。
